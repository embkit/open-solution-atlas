# 01-business / 流程

> 政务数据共享与交换平台的流程定义。每个流程均列明其触发条件、步骤以及约束这些步骤的规则。规则位于 `business-rules.md`（BR-xx）中，仅作引用，绝不重述。
>
> ⚠️ ASSUMPTION — 流程分解属于方案包的设计内容。国发〔2016〕51号 办法提供该领域的基本原则和共享类型定义，但不提供这些流程。

## P-01 — 登记

| | |
|---|---|
| **触发条件** | 提供部门登记一项数据资源 |
| **结果** | 一个**目录项**——根对象 |

1. 创建目录项，关联提供部门、资源、分类等级和共享类型（BR-01）。
2. 记录元数据、所有者和更新义务（BR-02）。
3. 标注为**不予共享**的分类必须附上不予共享依据（BR-03）。

> BR-01：目录项是根对象。没有目录项，授权便无可作用的对象；未列入目录的共享，对于治理该共享的流程本身也不可见。

## P-02 — 分类

| | |
|---|---|
| **触发条件** | 资源接入或重新分类 |
| **结果** | 一个**驱动**脱敏规则和访问规则的分类等级 |

1. 依据国家方法确定分类等级（BR-04）。
2. 根据等级推导脱敏规则和访问规则——按类别适用，而非按数据集适用（BR-04）。
3. 等级变更时重新推导规则，绝不修补原有规则（BR-04）。

> BR-04：分类分级是政策输入项，而不是标签。已记录但未执行的等级只是文档说明，而非管控措施。

## P-03 — 申请

| | |
|---|---|
| **触发条件** | 使用部门申请一项资源 |
| **结果** | 一项载明**使用用途**的申请 |

1. 载明使用用途、范围和期限（BR-05）。
2. 确定该资源的共享类型（无条件 / 有条件 / 不予共享）。
3. 对于**无条件共享**，无需逐一与各使用部门协商即可继续办理——但仍须记录（BR-06）。

## P-04 — 批准

| | |
|---|---|
| **触发条件** | 一项有条件共享申请 |
| **结果** | 一项**批准**，或一项**有依据的拒绝** |

1. 提供部门在其获委托的权限范围内作出批准。
2. 拒绝时须记录拒绝依据——资源为不予共享时，还必须提供不予共享依据（BR-03）。
3. 批准即创建授权。

## P-05 — 授权

| | |
|---|---|
| **触发条件** | 一项批准 |
| **结果** 一项**已记录、可撤销的授权** |

1. 创建授权：授给谁、哪项资源、哪种使用用途、什么范围、什么期限（BR-05）。
2. 授权**在设计上可撤销**（BR-07）。
3. **没有授权就不存在数据传输**——必须有已记录的授权，而不只是获得许可（BR-08）。

> BR-08 是 `AGENTS.md` 中的血缘闭环规则。没有授权的传输，就是参与了一个无法审计的闭环，也就是说，这是一笔无法追责的传输。

## P-06 — 交换

| | |
|---|---|
| **触发条件** | 一项已获授权的请求得到执行 |
| **结果** | 数据通过交换通道传输，并实施脱敏 |

1. 选择交换通道：库表（表到表）、文件或接口（BR-09）。
2. 发布前应用分类分级驱动的脱敏（BR-04）。
3. 将本次传输记录在授权项下（BR-08）。

## P-07 — 撤销授权

| | |
|---|---|
| **触发条件** | 授权到期、使用用途失效，或授权方撤销授权 |
| **结果** | 访问权限实际被移除，且具备可测量的提前量 |

1. 撤销授权。
2. 在平台侧移除使用部门的访问权限。
3. 记录撤销授权及其完成时间（BR-07）。

> BR-07：撤销授权的价值在于实际移除访问权限之前的**提前量**，而非记录撤销授权这一行为本身。授权虽然已被撤销但仍可使用，就只是名义上的撤销。

## P-08 — 治理与开放

| | |
|---|---|
| **触发条件** | 定期治理，或开放数据发布 |
| **结果** | 维护目录时效；使用 DCAT 元数据发布开放数据集 |

1. 根据更新义务审查目录时效（BR-02）。
2. 发现陈旧状态并转交提供部门处理（BR-10）。
3. 对于开放数据，生成数据集并使用 **W3C DCAT** 元数据进行描述（BR-11）。
4. 将提供部门持有的内容与已交付的内容进行一致性核对（BR-12）。

| 规则 | 流程 |
|---|---|
| BR-01 目录项是根对象 | P-01 |
| BR-02 目录时效 | P-01, P-08 |
| BR-03 拒绝要求有依据 | P-01, P-04 |
| BR-04 分类分级驱动规则 | P-02, P-06 |
| BR-05 授权记录使用用途、范围和期限 | P-03, P-05 |
| BR-06 无条件共享无需协商 | P-03 |
| BR-07 撤销授权提前量 | P-07 |
| BR-08 无授权不得传输 | P-05, P-06 |
| BR-09 所有通道均须声明 | P-06 |
| BR-10 陈旧状态有责任主体 | P-08 |
| BR-11 开放数据遵循 DCAT | P-08 |
| BR-12 双向一致性核对 | P-08 |
