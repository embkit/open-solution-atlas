共享闭环实验室 Closed-loop sharing lab

本页演示 packs/government-public/data-exchange 的核心决策（ADR-0005）： 授权 → 审批 → 共享 → 血缘是一个「环」而不是一条线。 每次共享都能走回到授权，每个授权都能走回到审批，血缘闭合回源资源 （BR-08 / FR-018）。需要这个 demo 的理由：这个闭环里任何一处断掉， 就是一次无法归因的传输——数据出去了，而没人说得清是谁基于什么授权的。

零容忍不变量

本包 7 个不可交易不变量。它们不是阈值：任何一个非零，「谁授权的？」 就变得无法回答或为假。第七个看起来像延迟信号而不是—— 已记录而访问仍存在的撤销，是被撤消费者仍在读的那个窗口， 而那些读每一次都不可归因。

渠道组成（table-to-table / file / interface）

BR-09 要求所有渠道都是已声明的一等公民，但「三者是否都一等、 还是有一条是主渠道」是记录的开放问题。本 demo 因此只提供 一种渠道，并标明这一点，而不是替你选一条主渠道。

结构化用途的表达能力

FR-013 要求用途可被检验——「消费者是否守约了？」不是一个平台 能对一个句子回答的问题。但覆盖真实用途的那个结构尚未设计； 它是 L3 的设计任务。本 demo 因此用一组固定选项，而不是一个自由文本框。
