## 本方案包覆盖什么

内部服务管理平台：为 IT（并延伸到 HR/行政共享服务）提供统一的服务门户与工单
主干，实现事件 / 请求 / 问题 / 变更 / 资产与配置管理流程，配套 SLA 时钟、知识库
与确定性自动化钩子。其核心承诺是：**每一项工作都有一条记录、一个责任人、一个
时钟、一个状态——而知识能跨越执行它的人而存续。**

## 范围内

- 服务门户：带权限约束的目录、知识库、公告、自助服务进度查询
- 工单内核：统一的事件/请求模型，影响×紧急度优先级，事件溯源的 SLA 时钟与
  明确的暂停规则，升级机制
- 对齐 ITIL 的流程（术语已引用，义务追溯到 ISO/IEC 20000-1）：问题管理与
  已知错误库，变更准入与风险分级及 CAB
- CMDB 内核：以注册表为先的配置项（CIs）与类型化关系，依赖视图，漂移对账闭环
- 自动化：带版本、确定性规则引擎，具备执行轨迹与试运行；AI 分诊仅作为扩展点
  （ADR-0003）
- 全渠道接入：门户、邮件（RFC 5322）、聊天桥接、监控告警——全部汇入同一条主干
  （ADR-0001）
- 报表：SLA 达成率、MTTR、积压、CSAT——均由事件日志按固定公式计算得出

## 明确不在范围内

- 监控平台本身（仅作为集成来源）
- 完整的 ITAM / 许可 / 财务资产管理（变体候选）
- 面向外部客户服务的 CRM 深度（独立方案包候选）
- SOAR / 安全编排（属集成，不属内核）

| ADR | 决策 |
|---|---|
| [ADR-0001](./04-architecture/adr/0001-single-ticket-backbone.md) | 单一工单主干；每个渠道都创建或关联工单并记录来源 |
| [ADR-0002](./04-architecture/adr/0002-event-sourced-history-clocks.md) | 仅追加的历史；SLA 时钟为折叠计算，报表为投影 |
| [ADR-0003](./04-architecture/adr/0003-deterministic-rules-ai-extension.md) | 确定性规则引擎优先；AI 分诊通过可追溯的扩展点接入 |
| [ADR-0004](./04-architecture/adr/0004-registry-first-cmdb.md) | CMDB 以注册表为先；数据馈送只给出建议并开启漂移任务，绝不改写真相 |
