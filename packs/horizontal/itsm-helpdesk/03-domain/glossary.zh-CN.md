# 03 · 术语表

> 双语关键术语。**std** 标记由所引用标准定义的术语；其余为本方案包的用法。

| 术语 | 中文 | 定义 |
|---|---|---|
| Ticket | 工单 | 一个工作项（事件或请求）的唯一记录；主干对象（BR-01） |
| Incident | 事件（故障） | 非计划的中断/降级；工单内核上的类型（**std** 结果集：ISO/IEC 20000-1 第 8.6.1 条） |
| Service request | 服务请求 | 从目录中履行的预定义请求（**std** 第 8.6.2 条） |
| Problem | 问题 | 针对复发/重大事件的根因工作记录（**std** 第 8.6.3 条） |
| Known error | 已知错误 | 已记录的原因 + 规避手段，等待修复（方案包用法；ITIL 术语） |
| RFC (request for change) | 变更申请 | 带风险分级与证据的变更提案（CTL-04） |
| CAB | 变更顾问委员会 | 常规变更的评估/审批机构（方案包用法） |
| CI (configuration item) | 配置项 | 带关系跟踪的类型化资产/要素（ADR-0004） |
| SLA | 服务级别协议 | 每个服务的协议目标（**std** 义务：ISO/IEC 20000-1 第 8.3 条） |
| SLA clock | SLA 时钟 | 事件溯源的响应/解决计时器，支持暂停/恢复（BR-04、NFR-002） |
| Business calendar | 业务日历 | 每个服务带生效日期的服务时间/节假日（BR-05） |
| Escalation | 升级 | 按职能（技能）或按层级（角色）重新分配的事件（BR-06） |
| Entitlement | 可见/可操作范围 | 决定谁能看到/处理工单或文章的范围（BR-11、CTL-03） |
| KEDB | 已知错误库 | 向智能体开放的已知错误库（FR-011） |
| Rule trace | 规则执行痕迹 | 应用到工单上的规则 id+版本标记（BR-14） |
| Drift | 配置漂移 | 观测到的 CI 状态与记录之间的偏差（FR-016） |
| MTTR | 平均修复时间 | 按报表所声明起点的平均解决时长（公式见 `non-functional.md`、FR-019） |
