# 04 · 可观测性

> ⚠️ ASSUMPTION — 所有阈值都是方案包默认值 `(A)`；部署时会被覆盖。见
> [`../SOURCES.md` §4](../SOURCES.md)。

## 黄金信号（服务台特有）

| 信号 | 定义 | 默认告警 `(A)` |
|---|---|---|
| 接入健康度（按渠道） | 工单创建速率与预期的对比；隔离数量 | 营业时间内任一渠道静默 > 30 分钟，或隔离量激增 |
| 时钟风险 | 处于违约预警阈值内的工单 | 每队列计数 > 阈值 |
| 无主工单 | 超过路由窗口仍无责任人的未关闭工单 | 任一条目 > 30 分钟 |
| 规则引擎错误 | 规则评估失败 / 部分拒绝 | 持续错误率 > 0 |
| SLA 评估器延迟 | 挂钟时间与最新时钟事件的差 | 延迟 > 5 秒 |
| CMDB 漂移积压 | 按账龄统计的未关闭漂移任务 | 任一 > 14 天 `(A)` |
| 重开率 / 复发 | 重开数 ÷ 关闭数；重复工单簇 | 按服务复盘做趋势告警 |

## 日志与追踪

- 每张工单一个关联 id，把接入 → 规则 → 时钟 → 升级 → 关闭 → CSAT 串起来
  （可追溯性主干，ADR-0002）。
- RuleTrace（规则 id + 版本）随每一个自动化动作一同传递。
- 日志用于诊断；事件日志才是真相记录。

## 派生 KPI（读模型）

- SLA 达成率 %、响应/解决分位数、MTTR（声明起点）、积压账龄、CSAT、复发率、
  CMDB 健康度。
- 目标按服务复盘从契约推导——**本方案包不主张任何数值 KPI 目标** `(A)`；
  公式固定在 `non-functional.md` 中。
