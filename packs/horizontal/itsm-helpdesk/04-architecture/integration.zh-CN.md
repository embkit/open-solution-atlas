# 04 · 集成

> 达到 L3 程度的集成清单；协议名称在 [`../SOURCES.md`](../SOURCES.md) 中
> 追溯；频率是方案包默认值 `(A)`。

## 集成清单

| # | 对端 | 方向 | 内容 | 协议 / 机制 |
|---|---|---|---|---|
| I-01 | 邮件服务器 / 网关 | 入 | 请求人邮件 → 工单；回复 → 备注 | RFC 5322 解析；SMTP/IMAP 接入 |
| I-02 | 聊天平台桥接 | 入/出 | 消息 → 工单；状态 → 渠道 | 平台 API + Webhook（需认证，BR-13） |
| I-03 | 监控 / 告警 | 入 | 告警 → 工单（按特征去重） | 标准告警载荷映射；Webhook |
| I-04 | SSO IdP（跨方案包 `iam-platform`） | 入 | 智能体/请求人身份认证、会话 | OIDC |
| I-05 | 发现 / 清单数据馈送 | 入 | 观测到的 CI 状态 → 漂移任务 | 文件/API 馈送（按 ADR-0004 仅为建议） |
| I-06 | 资产/监控类 CMDB 数据源 | 入/出 | CI 导入导出、健康信号 | API |
| I-07 | 通知渠道 | 出 | 指派/升级/违约通知 | SMTP / 平台消息 API |
| I-08 | 出站 Webhook（ITSM 相邻工具） | 出 | 供下游自动化使用的工单/变更事件 | HTTPS Webhook + JWS 签名载荷（RFC 7515） |
| I-09 | 报表数仓 / BI（跨方案包 `enterprise-bi`） | 出 | 事件/聚合导出 | 批量或流式，只读 |

## 契约规则

1. **身份由 SSO 掌管（I-04）：** 本方案包通过 OIDC 认证；它绝不存储口令
   （跨方案包，与 `iam-platform` 的 ADR 对齐）。
2. **渠道要么证明身份，要么被隔离（BR-13）：** 邮件采用邮件头/线程规则 +
   白名单；Webhook/告警须认证；无法解析的输入保留原始消息（FR-018）。
3. **先去重再创建（BR-01）：** 告警特征 / 线程键防止工单泛滥；合并保留来源。
4. **馈送只给建议（ADR-0004）：** I-05/I-06 开启漂移任务；它们绝不直接改动
   CI 记录。
5. **出站以事件为形（ADR-0002）：** I-08/I-09 消费投影或事件，绝不对可变表
   做查询。

## 数据流细节（L3）

| 流 | 频率 `(A)` | 幂等性 | 失败语义 |
|---|---|---|---|
| F-01 邮件 → 工单（I-01） | 投递后 `≤ 60 秒` | Message-ID + 线程键 | 解析失败 → 隔离并保留原始消息（NFR-007） |
| F-02 告警 → 工单（I-03） | 告警到达时；按特征去重窗口 `≤ 5 分钟 (A)` | 告警指纹 | 来源中断 → 接入健康度出现缺口，绝不静默 |
| F-03 聊天桥接（I-02） | 近实时 | 渠道消息 id | 渠道宕机 → 缓冲，重连后重放 |
| F-04 规则引擎作用于事件（内部） | 每事件同步执行；`≤ 100 毫秒 p95 (A)` | （工单，规则，版本） | 规则报错 → 标记工单 + 规则错误指标，不做部分应用 |
| F-05 SLA 节拍（内部） | 评估器延迟 `≤ 5 秒 p95 (A)` | 时钟事件 id | 延迟告警；正确性不受影响（基于折叠） |
| F-06 出站 Webhook/数仓（I-08/I-09） | 事件触发，至少一次投递 | 事件 id | 重试 + 死信队列；消费方去重 |
