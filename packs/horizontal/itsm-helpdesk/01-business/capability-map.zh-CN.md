# 01 · 能力地图

> CAP 的 ID 是稳定的；functional.md 向它们追溯。

| CAP | 能力 | 包含 |
|---|---|---|
| **CAP-01** | 服务门户与目录 | CAP-01.1 目录项与权限约束，CAP-01.2 知识库，CAP-01.3 公告/自助服务进度 |
| **CAP-02** | 工单内核 | CAP-02.1 统一接入（事件/请求），CAP-02.2 优先级（影响×紧急度），CAP-02.3 SLA 时钟，CAP-02.4 指派与升级 |
| **CAP-03** | 问题管理 | CAP-03.1 问题记录，CAP-03.2 已知错误库，CAP-03.3 复发关联 |
| **CAP-04** | 变更准入 | CAP-04.1 RFC 与风险分级，CAP-04.2 CAB 流程，CAP-04.3 实施与复核 |
| **CAP-05** | 资产与配置 | CAP-05.1 CI 注册表与关系，CAP-05.2 依赖视图，CAP-05.3 漂移检测，CAP-05.4 耗材库存 |
| **CAP-06** | 自动化与全渠道 | CAP-06.1 指派/路由规则，CAP-06.2 邮件转工单，CAP-06.3 聊天/Webhook 桥接，CAP-06.4 模板与宏 |
| **CAP-07** | 报表 | CAP-07.1 SLA 达成率，CAP-07.2 MTTR/MTBF/积压，CAP-07.3 CSAT |

## 边界（有意排除）

- 监控/告警平台本身 → 仅作为集成来源
- 完整的 ITAM（许可/财务资产）→ 变体候选
- 面向外部客户服务的 CRM 深度 → 独立方案包候选
- 安全工具链（SIEM/SOAR）→ 告警来源；本方案包做分级与记录，不取代 SOC 平台
