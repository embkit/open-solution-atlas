# 09-delivery · 里程碑

按依赖关系排序的构建计划。每个里程碑均可演示，且仅在通过其验证闸门后退出。任务 ID（`T-xx`）见 [`task-map.md`](./task-map.md)；AC ID 见 [`../08-quality/acceptance-criteria.md`](../08-quality/acceptance-criteria.md)。

| 里程碑 | 范围 | 退出闸门 |
|---|---|---|
| **M0 — 审计与域骨干** | 仅追加的哈希链审计存储、域范围界定中间件、IAM/RBAC 骨架、幂等基础机制 | AC-023, AC-024（隔离核心）；对预置的篡改场景进行链验证 |
| **M1 — 身份与 JML** | 身份/账号模型、SM-1、HRIS 数据接入、同步/对账（C-01..C-04） | AC-001..AC-004 |
| **M2 — 认证** | 按 BR-10/11 实施密码/认证因子、认证与升台阶认证、节流/锁定（C-05..C-07） | AC-005..AC-008 |
| **M3 — 单点登录与联邦** | OIDC/OAuth 端点、SAML 身份提供方、应用注册、JWKS/轮换、单点登出（C-08..C-13） | AC-009..AC-015 |
| **M4 — 授权平面** | 角色目录、策略版本管理、PDP 拒绝优先、职责分离授予检查（C-14..C-17） | AC-016..AC-019, AC-N03 |
| **M5 — 治理** | 访问请求、即时授权提权与应急访问、访问评审活动（C-18..C-20） | AC-020..AC-021；无常驻权限这一不变量 |
| **M6 — 同意与租户收尾** | 同意元组/撤回、密钥轮换、SCIM 出站传输与 SIEM 数据流（C-22..C-24） | AC-022, AC-025 |
| **M7 — 加固** | 性能场景、RPO/RTO 演练、安全负向测试套件、CI 中的协议互操作测试 | AC-N01..N07，完整 AC 清单 |

## 执行顺序说明

- M0 必须先于所有工作：先审计后执行（FR-022）和域隔离（BR-07）是每个后续契约的属性，而不是以后再加装的功能。
- M0 完成后，M4（PDP）可与 M2/M3 并行启动；M5 依赖 M4（提权属于决策式授予）和 M2（升台阶认证）。
- 协议互操作测试（M3 退出条件）针对**参考实现**运行，而不是仅做到自洽的桩实现——这是本方案包的核心正确性风险。
- 在 M7 阶段使用参考规模数据集执行性能闸门（AC-N01..N03）测试。
