# 09-delivery · 智能体可执行任务映射

每项任务对应一次聚焦的智能体变更，并附带验证钩子。ID 为 `T-xx`；每项任务都映射到一个里程碑以及 FR/BR/NFR/CTL/AC ID。按里程碑逐个执行；**不得跳过验证钩子**。

## M0 — 审计与域主干

- **T-01** 仅追加、哈希链式审计存储，并与业务写入处于同一事务
  (FR-022, C-21)。验证：API 层面的 UPDATE/DELETE 被拒绝；被篡改的行
  会破坏验证。 [NFR-009, CTL-05, AC-023]
- **T-02** 域范围中间件：在每次读取/写入/令牌操作上执行服务器端强制检查
  (BR-07)。验证：跨域探测矩阵均被拒绝。
  [NFR-013, AC-024]
- **T-03** 幂等原语：`(source, event_id, target, op)` 去重
  + 发件箱中继（integration §3）。验证：重新投递仅应用一次。
  [NFR-011, AC-N06]
- **T-04** 角色/RBAC 骨架，包含只读审计员和职责分离的管理员
  角色 (BR-08)。验证：自我审批路径被拒绝。[CTL-03, AC-020（一半）]

## M1 — 身份与 JML

- **T-05** 身份与账号模型、关联键唯一性、SM-1
  状态转换 (C-01, C-02)。验证：无效转换 → 422；重复键
  → 409。[FR-001, FR-002, AC-001, AC-002]
- **T-06** HRIS 事件摄取，具备幂等性且解供给优先
  (C-03)。验证：离职者与入职者竞态最终判定为禁用状态。[FR-003, BR-13,
  AC-003]
- **T-07** 同步作业：增量与全量对账、孤儿/冲突报告
  (C-04)。验证：检测到预置的孤儿账号，且不会静默覆盖任何内容。
  [FR-004, AC-004]

## M2 — 认证

- **T-08** 依据 BR-10 的密码凭证：泄露名单、无字符组合规则/轮换要求、内存困难型哈希 + pepper (C-05)。验证：上下文相关密码
  被拒绝；存储转储中不含明文。[FR-005, BR-10, AC-005]
- **T-09** 认证因子登记：TOTP / 通行密钥-WebAuthn / 恢复码，并
  绑定 AAL (C-06)。验证：按因子分配 AAL；恢复码仅可使用一次。
  [FR-006, BR-11, AC-006]
- **T-10** 认证 + 风险 + 升台阶认证流程，SM-2 (C-07)。验证：在完成升台阶认证前，
  AAL1 会话无法访问 AAL2 资源。[FR-007, AC-007]
- **T-11** 限流/锁定 + 统一错误，验证采用恒定时间 (C-07)。
  验证：突发流量 → 429；锁定某个因子后，其他因子仍可使用；账号存在性不泄露
  测试集通过。[FR-008, BR-06, AC-008]

## M3 — SSO 与联邦

- **T-12** OIDC 授权端点 + 令牌端点：PKCE/state/nonce、刷新令牌轮换及重复使用检测
  (C-08)。验证：未使用 PKCE 的请求被拒绝；nonce 重放失败；重复使用会吊销令牌家族。[FR-009, FR-010, BR-01, AC-009]
- **T-13** SAML 身份提供方：元数据验证、签名断言、绑定
  (C-09)。验证：被篡改的断言验证失败。[FR-011, AC-011]
- **T-14** 应用/RP-SP 注册，并限定受众范围 (C-10)。
  验证：受众不匹配的令牌被拒绝。[FR-012, BR-07, AC-012]
- **T-15** 按 issuer+subject 进行联邦关联，不使用上游密码
  (C-11)。验证：解除关联会终止会话，审计记录仍保留。[FR-013, BR-15,
  AC-013]
- **T-16** JWKS 轮换，允许 `kid` 重叠 + 内省契约
  (C-12)。验证：旧密钥在退役前仍能通过验证，此后验证失败。
  [FR-014, BR-01, AC-014]
- **T-17** 单点登出传播 + 全局吊销 (C-13)。验证：未覆盖的 RP 在访问令牌 TTL 内失效；离职人员的刷新令牌请求
  被拒绝。[FR-021, BR-02, AC-015, AC-022]

## M4 — 授权平面

- **T-18** 角色/权限目录及有效权限推导
  (C-14)。验证：各来源权限的并集与推导结果一致。[FR-015,
  AC-016]
- **T-19** 基于属性的访问控制（ABAC）策略验证 + 版本管理；执行中的决策记录版本
  (C-15)。验证：无效策略不会创建版本。[FR-016, AC-017]
- **T-20** 策略决策点（PDP）决策端点：拒绝优先、义务、决策依据、缓存失效、失败时关闭
  (C-16)。验证：允许+拒绝 → 拒绝；PDP
  宕机 → 失败时关闭；尝试覆盖策略执行点的行为会被审计。[FR-017, BR-14,
  AC-018, NFR-008]
- **T-21** 经职责分离（SoD）检查的权限项授予，包括间接冲突
  (C-17)。验证：有毒权限对被阻断；独立缓解措施获得批准；继承冲突被检测到。[FR-018, BR-03, AC-019]

## M5 — 治理

- **T-22** 访问请求 → 审批 → 限时授予
  (C-18)。验证：请求者自行认证被拒绝；授予立即在 PDP 中生效。
  [FR-019, AC-020]
- **T-23** 即时授权提权，配备自动吊销 + 强制应急访问评审
  (C-19, SM-4)。验证：到期后无需操作员干预即吊销；应急访问强制生成评审记录。[FR-020, BR-05, AC-021]
- **T-24** 访问评审活动：指派、升级，关闭时对未决定项执行吊销
  (C-20, BR-04)。验证：逾期默认吊销。[FR-020,
  AC-021（一半）]

## M6 — 同意与多租户收尾

- **T-25** 同意元组 + 将撤回记录为仅追加；传播路径
  (C-23)。验证：撤回绝不修改授予记录；处理目的相关处理停止。[FR-024, BR-12, AC-025]
- **T-26** 域管理员 + 机密/凭证轮换 (C-22)。验证：轮换后旧机密被拒绝；轮换无需停机。[FR-023,
  AC-024, AC-N07（一半）]
- **T-27** SCIM 出站流 + 来自发件箱的 SIEM 流 (C-24)。验证：账号禁用以幂等方式传播；SOC 收到按主体保持顺序的事件。
  [FR-003/FR-021 下游]

## M7 — 加固

- **T-28** 性能测试框架：参考负载下登录/令牌/JWKS/PDP 的 p95
  (AC-N01..N03)。验证：将实测 p95 与预算进行比较。[NFR-001..004]
- **T-29** 故障演练方案：存储终止（RPO/RTO）、PDP 网络分区、流量中的密钥轮换、对 10⁶ 行的审计链验证
  (AC-N04, AC-N05, AC-N07)。
  验证：演练通过；无需重新登记认证器。[NFR-006/007/009/010/012]
- **T-30** CI 中的协议互操作测试套件，对照参考 RP/SP/SCIM
  实现。验证：每个 PR 的符合性测试均通过。[FR-009..FR-014,
  NFR-014]
- **T-31** 安全负向测试套件：存在性泄露、alg 混淆、kid 注入、audience/realm 跨域、scope 权限提升、secret 扫描。
  验证：所有攻击均以失败关闭方式被阻止。[CTL-02/03/06, AC-N07]
- **T-32** 同意/擦除 + 导出范围界定运行：数据主体访问与擦除钩子保留审计事实；仅允许域范围内的导出。
  [FR-024, CTL-07, AC-025（扩展）]
