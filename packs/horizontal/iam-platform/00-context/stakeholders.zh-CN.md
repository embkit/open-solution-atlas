## 3. 作为行为主体的外部/上游—下游系统

- **HRIS**（Workday/SAP-SuccessFactors 类，按通用方式引用）— 权威员工身份主数据源；发出入职/调岗/离职事件。
- **目录服务**（LDAP/AD 风格）— 企业目录；根据部署架构类型，可能位于上游或下游。
- **SaaS 应用和内部应用** — 依赖方（RP）/服务提供方（SP），负责委托登录，并（对于 SaaS）消费 SCIM 供给。
- **资源服务/API/微服务** — 调用策略决策点（PDP）的策略执行点（PEP）。
- **SIEM / SOC** — 消费审计数据以及认证/决策遥测数据。
- **MDM / PKI** — 设备状态评估和证书/智能卡签发。
- **通知/SMS/电子邮件网关** — MFA 代码、安全通知和同意回执。
- **密钥管理/HSM** — 用于令牌、SAML 断言和机密的签名密钥。
- **ITSM/工单系统** — 访问请求可从此发起；供给状态会回传。

## 4. 行为主体主要目标

- 员工：通过快速、抗钓鱼的方法，在任意设备上只登录一次；绝不失去其合法需要的访问权限。
- 客户：顺畅地完成注册和登录；掌控自己的数据/同意。
- 审批人：查看清晰且带风险标注的请求；一次作出有把握的审批。
- 安全分析师：快速检测并吊销失陷的凭证/会话；准确了解主体能够访问的范围。
- 审计员：准确重建任何认证或授权决策（谁、执行了什么、何时、依据什么、结果如何）。
- IAM 管理员：无需更改代码即可调整身份/策略模型，并证明变更安全且可逆。
- 应用负责人：在数分钟内接入应用；将身份作为服务使用，而不是重新实现。
