# 08-quality · 测试策略

用于证明 NFR-001..NFR-014 和 CTL-01..CTL-07 的测试层级、覆盖率目标、测试数据以及性能/故障测试计划。AC 引用见 [`acceptance-criteria.md`](./acceptance-criteria.md)。

## 层级与覆盖率目标

| 层级 | 验证内容 | 特征 | 闸门 |
|---|---|---|---|
| 单元 | 领域不变量：BR-01 令牌/会话边界、BR-03 SoD 引擎、BR-10 密码检查、BR-13 优先级、BR-14 拒绝优先组合、SM-1..SM-5 转换守卫 | 纯逻辑，无 I/O | 策略/SoD/令牌/状态机引擎的行覆盖率 ≥ 90 % |
| 契约 | C-01..C-24 + 协议端点的 OpenAPI 3.1 符合性；RFC 9457 结构；域范围筛选；幂等标头 | 经模式校验 | 所有已文档化端点，包括 PDP 与合作伙伴接口 |
| **协议互操作性** | OIDC/SAML/WebAuthn 对参考实现的一致性（授权码流+PKCE、断言签名、认证器证明）；SCIM 2.0 载荷符合性 | CI 中使用参考 RP/SP/IdP/SCIM 服务器 | 使用真实库验证 AC-009..AC-014，而非自洽桩 |
| 集成 | HRIS JML → 身份 → SCIM 供给 → 会话 → 决策 → 审计；单点登出/吊销传播；ITSM 请求循环 | 临时存储 + 模拟 HRIS/SCIM/SIEM | 正常路径 + F-01..F-08 故障注入 |
| 状态机 | SM-1..SM-5 转换，包括拒绝非法转换；不存在通往常驻权限的路径；离职人员无法认证 | 基于模型 | 覆盖所有转换 |
| **安全负向测试** | 主体存在性不泄露；节流/锁定；受众/域越界矩阵；范围升级；尝试覆盖 PEP 的拒绝优先结果；仓库内密钥扫描；JWT 算法混淆/kid 注入/nonce 重放 | 攻击语料库 + SAST | 任何越界或泄露成功 = 红色 |
| 并发 | 重复的 JML 事件仅收敛一次；针对同一主体的并发提权请求不得超出时间窗语义；竞态下刷新令牌轮换的重用检测 | 并行测试工具 | 无重复授予；重用时吊销令牌族（NFR-011） |
| 属性测试 | 供给收敛不受投递顺序影响（AC-N06）；有效权限推导结果等于各来源权限的并集；审计链验证的确定性 | 基于属性，使用随机种子 | 每晚 10,000 个序列 |
| 降级 | PDP 宕机 → 故障时拒绝；JWKS 缓存可持续提供验证直至 TTL；存储故障切换 RPO/RTO 演练 | 混沌测试工具 | AC-018 后半部分、AC-N04 |
| 性能 | 参考规模下的 AC-N01..N03 登录/令牌/PDP 性能特征 | 负载生成器 | 跟踪回归；页面预算超限 |
| 控制项/审计 | 在 10⁶ 条记录上进行链验证；评审活动关闭语义（未决定时吊销）；同意撤回传播；导出范围限定 | 日志重放 + 负向测试 | 每次运行均有 CTL-01..CTL-07 证据 |

## 测试数据

- **身份语料库：** 100k 个员工型 + 1M 个客户型合成身份，覆盖 ≥ 3 个域，包含属性漂移、孤儿账号和重复关联键；JML 事件流包含乱序和重新投递事件。
- **凭证语料库：** 泄露密码列表样本、弱密码/上下文相关密码、通行密钥 + TOTP + 恢复码矩阵，以及按来源/设备产生的节流突发流量。
- **联邦语料库：** 参考 OIDC RP 与 SAML SP 元数据、断言篡改用例、已过期/已轮换的 JWKS 集、跨受众令牌。
- **策略语料库：** 拒绝优先排列组合、SoD 冲突集合（静态/动态/间接）、未定义属性策略、版本链。
- 不使用真实员工/客户数据；使用可控时钟控制 TTL、新鲜度窗口、提权到期时间和评审逾期阈值。

## 环境与晋级

```
PR        → 静态检查 + 单元 + 契约 + SM + 属性测试（快速）
merge     → 集成 + 协议互操作性 + 在暂存环境中进行安全负向测试
release   → 同一测试套件 + 性能配置 + RPO/RTO 演练 + 审计链运行
nightly   → 10,000 个属性测试序列 + 泄露密码列表刷新 + CVE 扫描
```

## 性能与故障测试计划

- **AC-N01/N02/N03：** 在 200k-session / 500 rps 形态的负载下运行登录、令牌和 PDP 测试工具并施加突发流量；对照预算断言实测 p95/p99。
- **故障注入：** 使身份存储宕机（AC-N04）；使 PDP 发生网络分区（故障时拒绝，JWKS 缓存有界）；丢弃一个 HRIS 会话后重放（收敛，AC-N06）；在流量期间轮换签名密钥（重叠生效，AC-N07）；破坏审计记录行（由审计链检测到，AC-N05）。
- **浸泡测试：** 在 24 h 峰值认证/决策负载下持续运行，监控会话存储增长、刷新令牌轮换的频繁变动、审计滞后和 DLQ 深度。
