# 04-architecture / 可观测性

指标、日志、追踪、业务/安全信号、SLO 和人员角色。追踪对应 NFR-014；支持 CTL-05（审计）和 CTL-04（特权治理）。

## 1. 三个遥测平面

1. **技术**：服务延迟/错误、令牌签发和 JWKS 健康状况、PDP 吞吐量/延迟、队列/发件箱滞后、缓存命中率、数据库健康状况。
2. **运营（身份）**：按方式和结果划分的认证量、MFA 注册覆盖率、供给成功率/漂移、访问评审活动进度、会话数量。
3. **安全（控制）**：登录失败率、锁定率、异常登录模式、升台阶认证频率、决策拒绝次数、SoD 阻断、提权授予/使用、吊销操作、跨域拒绝。

> 审计记录（BC-7）是安全证据的**权威来源**；遥测用于检测和 SLO，绝不能成为唯一的审计来源（CTL-05）。

## 2. 关键指标与信号

| 领域 | 指标 |
|---|---|
| 认证 | 登录成功/失败率、p95 延迟（NFR-001）、认证因子构成（密码/MFA/WebAuthn）、升台阶认证率 |
| 令牌 | 签发延迟（NFR-002）、刷新令牌轮换次数、重用检测事件、吊销延迟 |
| 授权 | 决策 p95/p99（NFR-004）、允许/拒绝比率、期望缓存命中、已发出的义务 |
| 生命周期 | 供给操作数/秒、成功/重试/隔离率、对账偏差、解供给延迟（NFR-005） |
| 治理 | 未结访问请求数/存续时长、评审活动完成率、逾期项、即时授权提权次数/持续时间 |
| 安全 | 登录失败激增、锁定、不可能旅行/新设备信号、跨域拒绝、SoD 阻断 |
| 平台 | 可用性（NFR-006）、发件箱→SIEM 延迟、审计摄取率（NFR-010）、错误率 |

## 3. 日志与追踪

- 结构化日志带有贯穿登录 → 会话 → 令牌 → 决策 → 供给全过程的**关联 ID**，并按域设置维度。
- 区分**审计事件**（不可变、经哈希链连接）与**技术日志**（受保留期限制、已脱敏）：绝不记录机密、令牌、密码或 OTP 值。
- 覆盖 IdP、PDP 和供给流程的分布式追踪；决策追踪会呈现策略版本及所查阅的属性来源（不泄露敏感属性值）。
- 域隔离适用于日志/仪表板：域范围的查看者只能看到该域的遥测数据（NFR-013）。

## 4. SLO 与告警（初始）

| SLO | 目标 | 告警阈值 |
|---|---|---|
| 认证延迟 | p95 ≤ 500 ms（NFR-001） | p95 > 800 ms，持续 5 分钟 |
| 令牌签发 | p95 ≤ 200 ms（NFR-002） | p95 > 400 ms，持续 5 分钟 |
| PDP 决策 | p95 ≤ 20 ms（NFR-004） | p95 > 50 ms，持续 5 分钟 |
| 核心可用性 | ≥ 99.95%/月（NFR-006） | 任何 sev-1 级中断 |
| 验证路径 | ≥ 99.99%/月（NFR-006） | JWKS 端点错误 |
| 解供给延迟 | ≤ 15 分钟（industry-brief §5） | 任何离职人员的访问权限未在 SLA 内被吊销 |
| 审计摄取完整性 | 仅追加、0 个缺口（NFR-009） | **完整性违规时呼叫值班人员** |
| 解供给偏差 | 对账后 0 个孤儿账号 | 任何仍处于活动状态的孤儿账号 |
| 登录失败异常 | 受基线约束 | 相较基线，峰值 > 阈值 |

## 5. 仪表板/人员角色

- **IAM 管理员**：认证/令牌/PDP 健康状况、供给漂移、应用接入状态。
- **安全分析师（SOC）**：异常登录、锁定、升台阶认证率和拒绝率、有效/已过期的提权、吊销时间线。
- **审批人/资源所有者**：待处理请求、评审活动项、需要缓解处理的 SoD 冲突。
- **审计/合规**：评审活动完成情况、证据导出状态、审计查询访问权限（只读）。
- **服务所有者**：各应用的令牌/决策量及错误率。

## 6. 合成/控制监控

- 持续断言**默认拒绝**（fail-closed）行为：模拟 PDP 不可用，并验证必须获得许可的操作均被拒绝（BR-14/NFR-008）。
- 定期重放一组模拟尝试（跨域令牌、过期刷新令牌重用、违反 SoD 的授予），并断言每次尝试均被拒绝——控制级健康检查（CTL-02/CTL-03/CTL-07）。
- 验证审计**哈希链连续性**及 JWKS 轮换重叠情况，并将其作为例行检查（BR-01/BR-09）。
