# 07 · 体验 — 关键流程

这不是视觉设计；它规定的是任何实现都必须遵守的交互契约。

## E-01 读者 — 文章页（公开）

**信息顺序**：标题 →（发布日期 · 最后修订日期 · 阅读时长）→ 正文 → 许可 →
标签/系列导航 → 提及/评论 → 文章导航。
- 排版：系统字体栈；行长 ≤ 72 字符；遵循 `prefers-reduced-motion` 与
  深色模式的系统偏好。
- 图片按固有尺寸懒加载（无布局偏移，CLS 目标为 0）。
- 默认部署中没有 newsletter 墙，也没有同意弹窗。

## E-02 读者 — 发现

- 头部常驻：首页、标签、归档、检索、RSS。
- 检索打开一个输入框，在首次获得焦点时懒加载 `search-index.json`；读者输入
  时结果随之更新（≥ 2 个字符）；Esc 关闭；可键盘操作。任何请求都不会离开
  本源。
- 标签/分类/系列页：标题、文章数、分页列表；零已发布文章的标签永远不会出现
  空状态（构建器不生成它）。

## E-03 作者 — 编辑器

双栏（Markdown / 实时预览），在窄屏上折叠为单栏预览标签页。
- **常驻状态胶囊**：`已保存 12:04:31` / `保存中…` / `离线 — 更改将同步`。
  绝不含糊（FR-002）。
- 发布按钮被禁用，并带有列出缺失字段的提示，直至发布闸门通过（FR-004）：
  给出确切清单，而不是笼统的「请完善」。
- 定时控件：绑定时区的日期/时间；确认行复述对应的绝对 UTC 时刻。
- 危险动作（取消发布、修改 slug、删除草稿）需要键入确认；修改 slug 的对话框
  **预览将创建的 301**。

## E-04 作者 — 媒体

- 拖拽 + 粘贴图片到编辑器；每个文件独立显示上传进度。
- 替代文本提示在**发布前是阻断性的**，并提供一键「标记为装饰性」的替代
  方案；已有但缺少替代文本的图片会出现在发布前检查清单中。

## E-05 作者 — 审核队列

- 列/过滤：待处理 / 已通过 / 已拒绝 / 已拉黑；每一行：来源站点、回链验证
  状态、提及类型标签、目标文章、接收时间、已清洗摘录。
- 一键通过（a）/ 拒绝（r）；拉黑来源刻意做成两步。
- 空状态：「没有待处理的提及 — 传入的回应会被自动验证。」
- 通过操作会排入一次重建；界面会说明哪个文章页将更新。

## E-06 必须被设计的状态

| 情形 | 必需的用户可见行为 |
|---|---|
| 发布后构建失败 | 作者看到一个红色 release 及其日志链接；公开站点仍在旧 release 上；提供明确的「重试」 |
| 定时文章错过（3 次失败） | 横幅 + 告警邮件；文章保持 SCHEDULED，不会半发布 |
| 读者命中旧 URL | 移动场景下 301 静默重定向；样式化的 410 页面，说明「本文已移除」并给出归档链接 |
| Webmention 端点被滥用 | 对滥用者静默返回 429；作者看到的是速率限制活动的汇总，而不是噪声 |
| 读者使用禁用 JS 的浏览器 | 完整内容、归档、订阅源可用，检索表单降级为一条指向标签的提示；核心阅读绝不依赖 JS |
