# 00 · 干系人

| 角色 | 身份 | 目标 | 约束 / 顾虑 |
|---|---|---|---|
| **作者 / 所有者** | 唯一的内容所有者；通常也是运营者 | 舒适地写作；可靠地发布；保有所有权与读者；低运营成本；最少维护 | 不是运维专家；可能数月不碰系统 |
| **读者（匿名）** | 公开访客 | 在任何设备/网络上快速阅读；找到旧文；订阅 | 期待秒开；无强制登录；对侵入性追踪反感 |
| **读者（评论者）** | 互动访客 | 无需注册账号即可留下回复 | 面临垃圾内容风险；也可能改为从自己的站点评论（Webmention） |
| **RSS/Atom 订阅者** | 机器角色（订阅阅读器） | 稳定、有效的订阅源，带稳定 GUID 与合理的更新语义 | 订阅源损坏 = 受众静默流失 |
| **搜索引擎爬虫** | 机器角色 | 发现内容；理解正本 URL | 站点地图有效性、元数据正确性 |
| **外部平台** | 联合发布目标（社交、聚合器） | 收到正本链接，并把提及发回 | API 会变；一律视为可选、可替换 |
| **作者未来的自己 / 迁移目标** | 维护角色 | 以可移植格式导出全部内容，零锁定 | 必须在原软件不再运行时依然可用 |

## 信任边界（摘要；细节见 04-architecture/security.md）

- **公开区**：静态页面、订阅源、站点地图——无机密、无写入路径。
- **创作区**：草稿编辑、媒体上传、发布动作——单一已认证身份，每个动作可归属。
- **接入边缘**：传入的 Webmention——不可信的外部输入；须经验证、排队、审核，
  绝不原样渲染。
