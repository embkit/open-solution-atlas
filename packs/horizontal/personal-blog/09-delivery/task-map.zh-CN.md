# 09 · 智能体可执行的任务地图

每个任务的规模都对应一次专注的智能体改动，并带一个验证钩子。ID 为 `T-xx`；
每个都映射到里程碑与需求 ID。按里程碑顺序执行；不要跳过验证钩子。

## M0 — 骨架与流水线

- **T-01** 定义内容仓库格式与同步：frontmatter 模式、仓库 watcher/轮询、到
  post_metadata 的投影。验证：夹具仓库能往返。 [FR-001]
- **T-02** 构建引擎：与预览共享的固定渲染器做 Markdown 渲染；页面/索引/
  订阅源/站点地图生成器置于同一个构建入口之后。验证：快照输出。
  [AC-001、AC-011/012]
- **T-03** 制品发布器：按哈希前缀上传、current-release 指针、刷新。验证：
  注入晋升中途失败 → 旧站点完好。 [AC-008、NFR-015]
- **T-04** Release 记录 + 回滚命令。验证：回滚在 5 分钟内提供上一个 release。
  [F-04]

## M1 — 创作内核

- **T-05** 管理端 SPA 外壳 + 位于隔离管理源上的 OIDC/bearer 会话。验证：
  未认证的 API 调用返回 401。 [NFR-007]
- **T-06** 文章 CRUD，配 EARS 对齐的校验、slug 规则 BR-03。验证：对照
  OpenAPI 的契约测试。 [FR-001/004]
- **T-07** 自动保存暂存区 + 修订追加日志 + 恢复为新修订。验证：AC-002 性质
  测试。 [FR-002]
- **T-08** 媒体上传：类型魔数嗅探、体积上限、sha 去重、替代文本/装饰性闸门、
  资源源站 + CSP。验证：AC-003 + XSS-as-svg 语料。 [FR-003、CTL-008]
- **T-09** 发布前闸门端点，返回确切的缺失字段/图片清单。验证：AC-004。
  [FR-004、BR-10]

## M2 — 发布与 URL

- **T-10** 带守卫的发布/取消发布状态机服务。验证：SM-01 的所有迁移，包括
  非法迁移被拒绝。 [FR-008/010]
- **T-11** 定时器 worker（1 分钟节拍、尝试次数、告警、幂等运行）。验证：
  时钟受控的测试 AC-009。
- **T-12** 重定向服务：构建器 + 边缘规则、环/链检测、410 页面。验证：
  AC-010 性质测试套件。 [BR-06]
- **T-13** RSS/Atom + 站点地图 + 正本/OG/JSON-LD 输出器，以及作为构建闸门
  的校验器。验证：AC-011/012。
- **T-14** 分类体系规范化/去重/上限 8 + 索引页。验证：AC-005/006。

## M3 — 读者体验与检索

- **T-15** 实现 E-01/02 的公开主题，含降低动效/深色模式、无 JS 阅读、
  安全响应头。验证：axe + 响应头测试、AC-N01。 [NFR-009]
- **T-16** 静态检索索引生成器 + 浏览器内检索界面。验证：AC-007，含排除
  草稿与无网络请求的断言。 [ADR-0004]

## M4 — 互动

- **T-17** Webmention 接收器：表单校验、队列、SSRF 安全的抓取器、微格式
  分类器、幂等存储。验证：AC-013 + SSRF 语料。
- **T-18** 清洗器 + 审核端点 + 队列界面 + 重建触发。验证：AC-014 XSS 语料。
  [CTL-008]

## M5 — 可观测性与安全

- **T-19** 构建闸门：链接检查、a11y、CVE、订阅源/JSON-LD。验证：闸门在
  植入缺陷时失败。
- **T-20** 可用性探针、告警渠道、管理端 release 状态、每周备份校验摘要。
  验证：混沌演练 AC-N02。 [F-01..F-09]

## M6 — 所有权与灾难恢复

- **T-21** ExportBundle 作业 + 恢复流程。验证：AC-017/018 在空环境中通过。
- **T-22** 快照调度、跨区域副本、演练脚本 + 成文操作手册。验证：每月演练
  AC-N04。

## M7 — 可选

- **T-23** 以功能开关控制的评论：速率限制、蜜罐/工作量证明、垃圾评分、
  同一审核队列。验证：AC-015。
- **T-24** POSSE 链接助手（手工优先）。验证：联合发布元数据存在；默认不做
  自动化第三方调用。 [BR-12]
