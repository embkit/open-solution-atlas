# 08 · 验收标准

每条 AC 都是一条可证伪的测试陈述，并映射到某条需求。这是 L3 方案包的「完成」
定义；编码智能体必须能够通过自动化测试或明确标注的人工检查来验证每一条。

## 创作与修订

- **AC-001**（FR-001）：给定一次 Markdown 编辑，标题、代码块、列表、引用与嵌入
  图片的预览输出在结构上与已发布页面的渲染逐字节一致。
- **AC-002**（FR-002）：编辑停止后 5 秒内触发自动保存；关闭并重新打开编辑器会
  恢复到最后一次保存的确切文本；每次保存都创建一条修订记录；恢复第 n 个修订
  会创建第 n+1 个修订（历史绝不被改写）。
- **AC-003**（FR-003）：上传非图片类型 → 415；6 MB 的 PNG → 413；没有替代
  文本的有效 JPEG 无法被嵌入随后发布的文章（发布被阻断，FR-004 的清单会
  指明具体是哪张图片）。
- **AC-004**（FR-004）：文章缺少标题/slug/标签/摘要/许可 → 发布返回 422 并
  列出每一个缺失字段；字段齐备 → 202 并创建 release 作业。

## 组织

- **AC-005**（FR-005）：标签 ` Python `、`python`、`PYTHON` 折叠为一个规范
  标签；第 9 个标签被拒绝；每个被用到的标签都存在 `/tags/<name>/` 页面，并
  按最新优先列出文章且计数正确。
- **AC-006**（FR-006）：按年/月的归档页恰好枚举 `published_at` 落在该窗口内
  的文章；草稿绝不出现。
- **AC-007**（FR-007）：在参考设备上，对 500 篇文章的索引检索一个出现在已
  发布文章中的词，300 毫秒内返回；只出现在草稿中的词返回空；不发出任何网络
  请求（通过网络面板验证）。

## 发布与 URL

- **AC-008**（FR-008）：发布返回 DEPLOYED；文章页、标签页、首页、RSS 与
  Atom 都包含新文章；在晋升中途中断会让上一个站点继续完整服务（注入失败 →
  不出现混合状态）。
- **AC-009**（FR-009）：定时在 T 的文章在 T+60 秒前发布；构建器连续失败 3 次
  时作者会收到告警，且文章不公开。
- **AC-010**（FR-010）：修改已发布文章的 slug 会创建一个可用的 301（旧→新）
  并更新内部链接；取消发布在原 URL 上返回 410；两个动作都不会产生裸 404。

## 分发

- **AC-011**（FR-011）：RSS 与 Atom 通过各自的官方校验器；编辑一篇文章会
  更新既有条目（同一 GUID）而不是新增重复项；只出现最新 20 篇文章。
- **AC-012**（FR-012）：站点地图恰好包含全部已发布 URL，不含草稿/410；每篇
  文章都有正本、OG/Twitter 标签与 JSON-LD `Article`；结构化数据校验器报告
  零错误。

## 互动

- **AC-013**（FR-013）：POST 的 target 畸形 → 400，不存储任何内容；target
  未知 → 400；不回链的来源 → 存为 REJECTED；有效回复 → 202 后为 PENDING；
  用同一来源重复发送会更新同一行（无重复）。
- **AC-014**（FR-014）：通过后重建即在文章上显示该提及；来源 HTML 中的原始
  `<script>` 不出现在渲染输出中；被拉黑的来源在后续发送时自动被拒。
- **AC-015**（FR-015）[若启用]：来自同一 IP 的 5 条快速评论 → 429；有效评论
  在通过之前保持不可见；功能关闭时 → 403。

## 洞察与所有权

- **AC-016**（FR-016）：默认部署在读者页面加载时发出零第三方请求（网络审计）；
  分析响应不含 IP，且无法跨天识别同一读者。
- **AC-017**（FR-017）：导出包包含每一篇文章、每个修订、每个媒体二进制、每个
  标签、每条重定向与每条已通过的提及，外加 `manifest.json`；不含 IP 或访问
  日志；SHA-256 列表可校验全部媒体。
- **AC-018**（FR-018）：把该包恢复到一套空安装中；100 % 此前已发布的 URL
  提供完全相同的内容；订阅源与重定向正常工作。

## NFR 闸门

- **AC-N01** 在代表性文章上运行 Lighthouse（移动端、限速 4G）：LCP ≤ 2.5 秒、
  CLS ≤ 0.05、a11y ≥ 95；CDN 命中 TTFB ≤ 200 毫秒（NFR-001）。
- **AC-N02** 关闭创作服务 24 小时：公开页面与订阅源全程返回 200；管理端显示
  降级模式（NFR-004）。
- **AC-N03** 用压测工具对 CDN 目标施加 100 倍基线请求速率并持续 1 小时：
  错误率为 0，源站无自动伸缩（NFR-003）。
- **AC-N04** 每周的备份恢复演练完成且内容校验和一致（NFR-005、CTL-010）。
- **AC-N05** 基线配置的月度成本符合文档记载的 ≤ 5 美元模型（账单复核；人工）。
