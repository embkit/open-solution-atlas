# 04 · 集成

## 集成清单

| # | 对端 | 协议 | 方向 | 数据 | 频率 |
|---|---|---|---|---|---|
| I-01 | 内容 Git 远程（托管或自托管） | HTTPS / SSH git | 双向 | Markdown 树、媒体、配置 | 每次保存/发布时；也是有效的人工通道 |
| I-02 | 对象存储 / 静态托管 | S3 兼容 API | 出 | Release 制品 | 每个 Release |
| I-03 | CDN 刷新 API | HTTPS REST | 出 | 失效路径/通配符 | 每个 Release |
| I-04 | 外部 Webmention 发送方 | HTTP `POST`（表单编码） | 入 | source、target URL | 事件驱动 |
| I-05 | 提及的来源页面 | HTTP `GET`，出站 | 出 | 用于链接验证的 HTML 抓取 | 每条入站提及 |
| I-06 | 订阅阅读器 / 爬虫 | HTTP `GET` XML | 出 | RSS/Atom、站点地图 | 轮询驱动 |
| I-07 | 认证提供方（可选的委托登录） | OAuth 2.0 / OIDC | 双向 | 仅作者身份 | 登录时 |
| I-08 | 告警渠道 | SMTP 或 Webhook | 出 | 定时/构建失败 | 失败时 |
| I-09 | 联合发布目标（可选） | 对方的 API/手工 | 出 | 仅正本链接 | 手工（POSSE） |

## 契约规则

- **入站按定义就是不可信的**（I-04/I-05）：模式校验、体积上限、出站 SSRF
  白名单（无私网 IP 段、无云元数据端点）、重定向跟随上限、超时 ≤ 5 秒。
- **出站发布路径是幂等的**：上传到以内容哈希为键的带版本前缀；晋升是单次
  指针/元数据切换；重试是安全的（NFR-015）。
- **除显式、需主动启用的集成外，没有读者数据离开本系统**（追踪清单，
  CTL-002）。
- **外部 API 会降级，但绝不阻塞发布**：I-03/I-08/I-09 的失败不得回滚一个
  已成功的 Release；它们会排队并告警。

## 一条提及的数据流（详细）

```
POST /webmention ──▶ 校验表单 ──▶ 入队作业（立即返回 202）
                                              │
                            抓取来源（出站白名单，声明 UA）
                                              │
                 解析 HTML（沙箱化）──▶ 查找 <a href=target>
                      │ 不存在/不可达 ──▶ 标记 REJECTED
                      ▼ 存在
            分类微格式（h-entry）：reply/like/repost/bookmark
                      ▼
            存为 PENDING（已清洗摘录）──▶ 审核队列
```
