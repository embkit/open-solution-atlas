# 01-business / 流程

> 电力营销 / CIS 套件的流程定义。每条流程指明其触发条件、步骤，以及约束其步骤
> 的规则。规则位于 `business-rules.md`（BR-xx），此处只引用、不复述。
>
> ⚠️ ASSUMPTION — 流程分解属于方案包设计。没有为它引用任何外部标准。

## P-01 — 建档

| | |
|---|---|
| **触发** | 一个客户开始用电，或一个服务点发生变更 |
| **结果** | 一条客户记录、一个账户、一个服务点、一块电表，以及一次电价分配 |

1. 创建**客户**记录——当事方。
2. 创建**账户**——计费关系，有自己的生命周期。
3. 创建**服务点**——物理供电点。
4. 挂上**电表**。
5. 按客户分类分配电价。

> BR-01：客户、账户与服务点是**彼此不同的对象**，各有不同的生命周期。把它们
> 折叠起来，会让服务点变更看起来像客户变更，从而同时污染计费关系与统计记录。

## P-02 — 抄表

| | |
|---|---|
| **触发** | 一个计量周期 |
| **结果** | 读数、被提出的异常，以及**只由规则产生并带标注**的估抄 |

1. 通过自动采集（AMR/AMI）或现场抄表采集。
2. 与历史校验：缺失、超范围与不一致的读数成为**异常**（BR-04）。
3. 在取不到读数的地方，按**既定规则**应用估抄，并把结果标注为估算
   （BR-05）。
4. 记录读数及其**采集方式**。

> BR-05 是这个流程中承重的规则：一个被静默代入的估算会产生一张**算术正确
> 而事实无据**的账单——客户无法证伪，供公司无法举证。

## P-03 — 电价

| | |
|---|---|
| **触发** | 读数存在 |
| **结果** | 在**带生效日、带版本**的规则下计算出的费用 |

1. 解析该期间生效的**电价规则版本**（BR-08）。
2. 拆分任何跨越生效日的期间，每一段按当时生效的版本计算（BR-08）。
3. 产出费用，并打上其规则版本的戳。

> BR-08 使引擎成为受治理的算术，而那枚戳使一笔历史费用可解释，而不只是被
> 留存。

## P-04 — 出账

| | |
|---|---|
| **触发** | 一个周期关闭 |
| **结果** | 一张可从其事件重新生成的发票 |

1. 汇总该周期的费用。
2. 以**经批准的调整**应用更正——原账单保留（BR-09、BR-10）。
3. 产出发票，**带上**每笔费用计算所依据的**规则版本**（BR-11）。

## P-05 — 收费

| | |
|---|---|
| **触发** | 一张发票开出 |
| **结果** | 款项被入账，或走应收路径 |

1. 从任意渠道接收款项并按规则分摊。
2. 把未付发票按账龄纳入催收。
3. 升级到催收处置。

## P-06 — 服务与保障

| | |
|---|---|
| **触发** | 客户联系 95598，或一次停电影响到客户 |
| **结果** | 一个带真实上下文、被派工并归档的案件 |

1. 弄清客户的真实处境：账户、电表、读数历史、未付费用，以及任何相关的
   停电（BR-06）。
2. 创建一张与服务实例关联的故障工单。
3. **经由接口**派发现场作业（BR-02）。
4. 以记录的解决方案归档。

> BR-06：第 1 步不应要求转接。一个看不到读数历史的客服界面是一本电话号码簿。

## P-07 — 停复电

| | |
|---|---|
| **触发** | 一个欠费或政策条件 |
| **结果** | 一次带护栏、可审计的行为——或者一次拒绝 |

1. 提出该行为。
2. 流程把资格类别、通知期与受限时段**作为被强制的状态求值**（BR-15）。
3. 任一护栏不通过即阻断。
4. 把这次求值、其输入与其结果记录为完整的决策记录。

## P-08 — 对账

| | |
|---|---|
| **触发** | 定期 |
| **结果** | 费用事件与**双方**完成对账 |

1. 与**订单**对账——可归因于所供应的内容（BR-12）。
2. 与**库存**对账——用量总归属于某人（BR-12）。
3. 关闭缺口：有量无客户，以及有开通无费用。

> BR-12：对账只有双向运行时才承重。单向对账产出的系统计费正确，却对泄露
> 完全失明。

## 规则覆盖

| 规则 | 流程 |
|---|---|
| BR-01 客户/账户/服务点彼此不同 | P-01 |
| BR-02 仅限接口 | P-06 |
| BR-03 商业决策绝不查询网络状态 | P-01、P-06 |
| BR-04 抄表异常 | P-02 |
| BR-05 估抄按规则并带标注 | P-02 |
| BR-06 客服看到真实处境 | P-06 |
| BR-07 客服不能改变网络状态 | P-06 |
| BR-08 电价规则带版本 + 生效日 | P-03、P-04 |
| BR-09 费用事件不可变 | P-03、P-04 |
| BR-10 经审批更正、原件保留 | P-04 |
| BR-11 发票携带规则版本 | P-04 |
| BR-12 双向对账 | P-04、P-08 |
| BR-13 按类别留存 | P-08 |
| BR-14 词汇采纳而非合规 | （架构） |
| BR-15 护栏由流程强制 | P-07 |
