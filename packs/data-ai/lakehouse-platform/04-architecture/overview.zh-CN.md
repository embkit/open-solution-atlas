## 必须保持显式的两条接缝

### 1. 原始 → 规范化

这是承重的接缝，而且它在一个特定意义上是单向的：**规范化读原始，而没有集市
读原始**（BR-04）。理由不是卫生——而是规范化是源头特有的混乱只被解决一次、
为所有人解决的地方，而一个读原始的集会以不同方式重新解析它。

### 2. 规范化 → 集市

集市是派生的、可丢弃且可重建的。一项只存在于某个集市之中的转换，就是一项其
重建是一次重构的转换（BR-08）。

## 部署视图

```
   ┌────────────────────────────┐   ┌───────────────────────────┐
   │  对象存储                  │   │  算力（弹性）             │
   │  原始（仅追加）            │◀──│  接入 · 规范化 ·          │
   │  规范化（分区化）          │   │  集市 · 重处理            │
   │  集市（可重建）            │   └─────────────┬─────────────┘
   └────────────────────────────┘                 │
                                                  ▼
   ┌────────────────────────────┐   ┌───────────────────────────┐
   │  表格式 / 目录             │   │  编排器                   │
   │  快照 · schema 演进        │   │  感知分区 ·                │
   │  （部署选择）              │   │  幂等键                    │
   └────────────────────────────┘   └─────────────┬─────────────┘
                                                  │
              ┌───────────────────┬───────────────┼───────────────┐
              ▼                   ▼               ▼               ▼
   ┌────────────────┐  ┌────────────────┐ ┌──────────────┐ ┌─────────────┐
   │ 质量闸门        │  │ 血缘存储        │ │ 访问         │ │ 生命周期     │
   │ （阻断/告警）   │  │ （字段+版本）  │ │ 策略存储     │ │ 删除 ·      │
   └────────────────┘  └────────────────┘ └──────────────┘ │ 留存       │
                                                           └─────────────┘
```

**部署决策及其理由：**

| 组件 | 位置 | 理由 |
|---|---|---|
| **原始** | 仅追加的对象存储，绝不重写 | 重算依赖它；一次编辑会在多年之后才被发现（BR-02） |
| **规范化** | 分区化的表，幂等构建 | 「重载上周二」必须是一等能力（BR-11） |
| **集市** | 可重建、可丢弃 | 集市不是真相来源（BR-08） |
| **质量闸门** | 位于规范化与集市之间，作为一道硬边界 | 一次阻断性失败必须把该分区扣留给**每一个**消费方，而不是在读取时过滤（BR-06） |
| **访问** | 平台自身的强制执行点 | 一个 notebook 也是消费方；放在 BI 工具里的控制不是控制（BR-09） |
| **生命周期** | 一条带被记录结果的流水线 | 删除是运行式的，不是向每个消费方发一张工单（BR-12） |

## 这套架构刻意不做的事

- 不对原始记录做就地编辑（BR-02）。
- 没有集市读原始（BR-04）。
- 没有未经显式且有归属的动作就改变闸门分类（BR-06）。
- 没有拥有绕过路径的消费方，包括 notebook、导出与馈送（BR-09）。
- 没有只到表级的血缘（BR-10）。
- 没有全局留存设置（BR-13）。
- 没有不局限于其分区范围的重处理（BR-11）。
