# 03-domain / 术语表

> 在此定义的术语在本方案包中只有唯一含义；此后不引入同义词。`来源`记录依据：
> **[AGENTS]** 本方案包 `AGENTS.md` 的设计立场，**[PACK]** 本方案包的定义，
> **[CONV]** 没有单一标准的行业惯例，**[STAT]** 该领域的标准统计实践，但不是
> 本方案包采纳的规范标准。

## 1. 事件与 schema 注册中心（主干）

| 术语 | 中文 | 定义 | 来源 |
|---|---|---|---|
| **Event** | 事件 | 某一时点被记录的一次发生，带名称、属性、身份与时间戳。**只到达一次**——它无法以不同的形态被重新摄入。 | [PACK] |
| **Event schema** | 事件 Schema | 一个事件的已声明契约：名称、属性名、类型、含义与归属团队。 | [AGENTS] |
| **Schema registry** | Schema 注册中心 | 声明、校验、版本化并废弃 schema 的主干服务。 | [AGENTS] |
| **Declare-before-emit** | 先声明后上报 | 任何客户端都不得发出 schema 未被声明的事件的规则。对抗不可复现数字的唯一防线。 | [AGENTS] |
| **Schema version** | Schema 版本 | 一个事件契约的一次不可变修订。 | [PACK] |
| **Property migration** | 属性迁移 | 从一个已废弃属性名到其后继者的显式、带版本的映射，使历史查询保持可解释。 | [PACK] |
| **Quarantine** | 隔离区 | 存放校验失败事件的存储，**保留理由**。这是关于埋点健康的信号，不是垃圾桶。 | [PACK] |
| **Ungoverned event** | 未治理事件 | 一个没有 schema 的事件。不可复现数字的源头：一次改名在没有任何 diff 的情况下改变历史。 | [AGENTS] |

## 2. 身份

| 术语 | 中文 | 定义 | 来源 |
|---|---|---|---|
| **Anonymous identifier** | 匿名标识符 | 用户在被识别之前的标识符——设备、Cookie 或生成的 id。 | [CONV] |
| **Known user** | 已知用户 | 与账户、CRM 记录或支付身份关联的用户。 | [CONV] |
| **Identity resolution (ID stitching)** | 身份归并 | 把匿名标识符、设备、会话与已知用户关联成一个档案。 | [CONV] |
| **Merge** | 合并 | 把两个身份并入一个档案，**并把合并记录下来**。 | [AGENTS] |
| **Unmerge** | 拆分/撤销合并 | 撤销一次合并，**并传播到派生事实**（漏斗、人群、实验分配）。 | [AGENTS] |
| **Join key** | 关联键 | 一次合并所用的标识符。它的存续会击败删除：一个被删除的档案可以从残留中重新组成。 | [PACK] |
| **Derived fact** | 派生事实 | 任何从身份图计算出来的东西——人群成员资格、漏斗步骤、归因信用——因此一次撤销或删除必须抵达它。 | [PACK] |
| **Profile** | 用户画像/Profile | 一个身份的历史与特征的合并视图。 | [CONV] |

## 3. 同意

| 术语 | 中文 | 定义 | 来源 |
|---|---|---|---|
| **Purpose** | 使用目的 | 数据被处理的一个已声明、有边界的理由（产品分析、活动投递、广告报表）。同意是**按目的**限定的，而不是全局的。 | [AGENTS] |
| **Consent state** | 同意状态 | 某个身份在某个时点的按目的限定状态，而不是注册时的一个布尔值。 | [AGENTS] |
| **Collection-time enforcement** | 采集时执行 | 在适用的目的下，把关一个事件是否被采集。 | [AGENTS] |
| **Activation-time enforcement** | 使用/触达时执行 | 把关已采集的数据是否被*用于*某个目的——发到活动、上传到网络、丰富档案。 | [AGENTS] |
| **Revocation** | 撤回同意 | 撤回某个目的，**在两个点上立即生效**。 | [AGENTS] |
| **Residue** | 残留 | 从存续的连接键或派生事实中重新形成一个已删除身份的数据。删除必须处理的那种失败模式。 | [PACK] |

## 4. 分析

| 术语 | 中文 | 定义 | 来源 |
|---|---|---|---|
| **Funnel** | 漏斗 | 从起始事件到转化的有序步骤，度量每一步的流失。 | [CONV] |
| **Cohort** | 群组 | 按共同起始条件分组、并随时间跟踪的用户。 | [CONV] |
| **Retention** | 留存 | 一个群组在一段时间后仍然活跃的比例。 | [CONV] |
| **Attribution model** | 归因模型 | 在各触点之间分配信用的规则。平台必须支持多种，因为选择是一个业务决策。 | [PACK] |
| **Path analysis** | 路径分析 | 在事件之上的序列发现——描述性的，绝不是因果的。 | [CONV] |
| **Descriptive vs. causal** | 描述性 vs. 因果性 | 漏斗、人群与归因是**描述性**的；只有实验能确立因果。这是一条能力边界，不是一句免责声明。 | [PACK] |

## 5. 实验——决定一个结果是否有意义的那些术语

`AGENTS.md` 要求真正的统计。以下机制被定义得如此，是为了让它们的**缺失**可被
检测。

| 术语 | 中文 | 定义 | 来源 |
|---|---|---|---|
| **Randomisation** | 随机化 | 随机地、可复现地、按单元分配曝光。不是一条发布规则。 | [CONV] |
| **Assignment** | 分配 | 单元到处理的记录映射，住在**实验引擎**里，而不是交付系统里。 | [AGENTS] |
| **Sample size / power** | 样本量与统计功效 | 为检出某个效应量所需的预先承诺的观测次数。在实验开始**之前**声明。 | [CONV] |
| **SRM — sample ratio mismatch** | 样本比例不匹配 | 观测分配比例与预期分配比例之间被检测出的失衡。这是一个**分配缺陷**，不是结果——若不度量，它看起来与结果一模一样。 | [CONV] |
| **Guardrail metric** | 护栏指标 | 一个不得退化的健康指标（延迟、取消、退款、退出），主指标才算数。 | [CONV] |
| **Holdout** | 对照组/长期对照 | 一个刻意不暴露的总体，用以度量实验计划本身是否仍然有效。 | [AGENTS] |
| **Peeking** | 中途偷看 | 因为一个好看的中期结果而提前停止实验。统计上必然抬高假阳性；由预先声明的决策规则看守。 | [CONV] |
| **Novelty / primacy effect** | 新奇/首因效应 | 由新鲜感或对习惯的打断造成的短期行为变化，被误读为长期效应。 | [CONV] |
| **Decision rule** | 判定规则 | 预先承诺的、什么结果会让实验上线、搁置或砍掉的陈述。在读数之前声明。 | [PACK] |
| **Percentage comparison** | 百分比对比 | `AGENTS.md` 点名*不够*的东西。一个没有检验力、SRM、护栏、保留组与偷看纪律的差异是一张图，不是一次度量。 | [AGENTS] |

## 6. 分群、激活与目的地

| 术语 | 中文 | 定义 | 来源 |
|---|---|---|---|
| **Segment** | 人群 | 按条件选择成员的定义，被解析为**某一时点的快照**——绝不是实时视图。 | [PACK] |
| **Activation** | 触达/激活 | 把一个人群应用到某个目的：活动发送、广告上传、丰富。第二个强制执行点。 | [AGENTS] |
| **Destination** | 目标渠道 | 分群被发往的消息或广告平台。**在抽象层之后。** | [AGENTS] |
| **Destination abstraction** | 目标抽象 | 在众多目的地之上的一个接口，把平台的事件模型映射到每个目的地的 schema。 | [AGENTS] |
| **Data owner** | 数据所有者 | 对事件模型与身份模型的权威。**平台**拥有它；目的地从不拥有。 | [AGENTS] |
| **Reconciliation** | 对账 | 把平台指标与目的地自己回报的数字做交叉核对。反复出现，却没人预留预算。 | [PACK] |
| **Schema-versioned export** | 带 Schema 版本的导出 | 携带其事件 schema 版本的导出，使下游含义可被追溯而不是被假定。 | [PACK] |

## 7. 约定

- **「不得」**标记一条违反即为缺陷的规则——事件不得在其 schema 被声明之前发出；
  目的地不得拥有数据模型；分配不得住在交付系统里；删除不得留下连接键。
- **无同义词**：本方案包用 **event** 指单次发生，用 **profile** 指合并后的身份；
  **merge** 与 **unmerge** 是两个不同操作；**collection** 与 **activation** 是
  两个不同的强制执行点；**segment** 指定义，**member snapshot** 指解析出的
  名单。
