# AGENTS.md — Growth Analytics (L1)

L1 brief. At L2: the event schema registry is the spine — ungoverned events
make every number unrepeatable; experiment platform needs real statistics
(sample size, SRM, guardrails, holdouts), not percentage comparisons;
identity merging must be reversible/deletable for privacy; consent state
enforced at collection and at activation; ad networks are destinations
behind an abstraction, never the data owner.
