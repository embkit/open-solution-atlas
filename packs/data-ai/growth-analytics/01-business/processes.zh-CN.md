# 01-business / 流程

> 增长分析与实验平台的流程定义。每条流程指明其触发条件、步骤，以及约束其步骤
> 的规则。规则位于 `business-rules.md`（BR-xx），此处只引用、不复述。
>
> ⚠️ ASSUMPTION — 流程分解属于方案包设计。没有为它引用任何外部标准。

## P-01 — 声明

| | |
|---|---|
| **触发** | 产品或分析侧需要一个新事件或新属性 |
| **结果** | 一个 schema 在任何客户端发出它**之前**就在注册表中被声明并版本化 |

1. 声明事件：名称、属性、类型、含义、归属团队。
2. 为 schema 做版本。
3. 发布到注册表。

> BR-01：「先声明后发出」这条规则，是对抗不可复现数字的唯一防线。一个事件只
> 到达一次；没人能用不同的属性名重新摄入上个季度。

## P-02 — 采集

| | |
|---|---|
| **触发** | 一个客户端发出一个事件 |
| **结果** | 一个被校验通过的事件，或一个**带着理由**被隔离的事件 |

1. 按已声明的 schema 校验传入事件。
2. 成功时接入，并记录 schema 版本。
3. 失败时隔离，**并附上理由**（缺字段、类型错误、未知属性、版本不匹配）。

> BR-02：带理由的隔离是埋点健康信号。没有理由的隔离是一个垃圾桶，而本方案
> 包把这视为缺陷。

## P-03 — 解析身份

| | |
|---|---|
| **触发** | 一个事件到达 |
| **结果** | 一个被记录、可逆、可删除的档案关联 |

1. 解析匿名标识符、设备、会话与已知用户。
2. 创建合并，**并把合并记录下来**（BR-03）。
3. 记录该合并所用的连接键（BR-04）。
4. 派生事实——人群、漏斗步骤、归因信用（BR-04）。

> BR-03/BR-04：一个无法撤销的合并，就是关于某个人的一个谁也无法更正的决定；
> 而一个留下连接键的删除，让身份可以从残留中重新组成。

## P-04 — 分析

| | |
|---|---|
| **触发** | 分析师提出一个问题 |
| **结果** | 一个漏斗、人群、留存或归因结果 |

1. 在解析后的身份图上计算。
2. 漏斗、人群、留存、归因、路径分析。
3. 每个结果都是**描述性**的——绝不做因果论断（BR-06）。

## P-05 — 实验

| | |
|---|---|
| **触发** | 决定运行一个实验 |
| **结果** | 一个带预先声明决策规则的、随机化且可核查的实验 |

1. **在读数之前声明决策规则**——上线、搁置或砍掉（BR-08）。
2. 为声明的效应量计算所需的**样本量**（BR-07）。
3. 随机化，并把分配**记录在实验引擎里**（BR-05）。
4. 核查分配比例（**SRM**）（BR-07）。
5. 度量主指标**与**护栏指标（BR-07）。
6. 在计划需要时对照**保留组**比较（BR-07）。
7. 只在预先声明的时点读数——偷看由决策规则看守（BR-08）。

> BR-05：分配必须住在实验引擎里，而不是开关/交付系统里，否则比例无法核查、
> SRM 无法计算。

## P-06 — 激活

| | |
|---|---|
| **触发** | 一个分群被应用到某个目的 |
| **结果** | 分群在**该目的的同意状态**下被发往目的地 |

1. 把分群解析为一个**某时刻的成员快照**（BR-12）。
2. 在**激活**处检查该目的的同意状态（BR-11）。
3. 经由**抽象层**把平台的事件模型映射到目的地的 schema（BR-13）。
4. 发送，并记录这次发送及其目的与同意依据。

## P-07 — 撤回

| | |
|---|---|
| **触发** | 同意被撤回，或收到擦除请求 |
| **结果** | 采集与激活都停止，且身份被移除 |

1. 立即为该目的停止**采集**（BR-11）。
2. 立即停止**激活**（BR-11）。
3. 删除档案、**连接键**与**派生事实**（BR-04）。

## P-08 — 导出

| | |
|---|---|
| **触发** | 定期或按需 |
| **结果** | 带 schema 版本的精选事件与实验结果进入数仓 |

1. 携带其 **schema 版本**导出事件（BR-02）。
2. 导出，使下游含义可被追溯而不是被假定。

## 规则覆盖

| 规则 | 流程 |
|---|---|
| BR-01 先声明后发出 | P-01 |
| BR-02 记录 schema 版本；隔离带理由 | P-02、P-08 |
| BR-03 合并被记录且可逆 | P-03 |
| BR-04 删除覆盖连接键 | P-03、P-07 |
| BR-05 分配在实验引擎中 | P-05 |
| BR-06 描述性 vs. 因果性 | P-04、P-05 |
| BR-07 真正的统计 | P-05 |
| BR-08 决策规则预先声明 | P-05 |
| BR-09 目的地在抽象层之后，绝非所有者 | P-06 |
| BR-10 平台拥有该模型 | P-06 |
| BR-11 同意在采集与激活处强制 | P-06、P-07 |
| BR-12 分群是快照 | P-06 |
| BR-13 词汇采纳 | P-06、P-08 |
