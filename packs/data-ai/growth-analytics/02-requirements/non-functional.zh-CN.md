# 02 · 非功能需求

> 可度量的目标。**标注 `(A)` 的数值目标是策略假设，不是事实**——记录下来是为了
> 能被锁定、争论和修改；它们的依据见
> [`../SOURCES.md` §4](../SOURCES.md)。
>
> 公式被固定下来，以便任何一方都能复算出同一个数字。没有公式的目标只是一个
> 愿望。
>
> `verification: unverified` —— 目标属于方案包设计。

## NFR-001 — 先声明后发出的合规率
- **目标 (A)**：已发布客户端发出的事件中，100% 有已声明的 schema 版本。
- **公式**：`count(有已声明 schema 的事件) / count(来自已发布客户端的事件)`。
- **依据**：BR-01；一个未声明的事件在结构上就不可复现。

## NFR-002 — 隔离理由完整度
- **目标**：被隔离的事件中，100% 带有理由。
- **公式**：`count(带理由的被隔离事件) / count(被隔离事件)`。
- **依据**：BR-02；没有理由的隔离是一个垃圾桶，不是一个信号。

## NFR-003 — 合并/撤销比例
- **目标 (A)**：跟踪撤销率，且从合并错误上报到撤销应用的 p95 ≤ 24 小时。
- **公式**：`unmerge_applied_ts - error_reported_ts` 的 p95。
- **依据**：BR-03；一个无法撤销的合并，就是关于某个人的一个无法更正的决定。

## NFR-004 — 删除完整度
- **目标**：已受理的擦除请求中，100% 移除档案、连接键与派生事实。
- **公式**：`count(三者皆被移除的请求) / count(请求)`。
- **依据**：BR-04；留下连接键的删除允许重新识别。

## NFR-005 — 实验分配完整性
- **目标**：100% 的实验在引擎中记录了分配，且 0 个 SRM 检测未被处理。
- **公式**：`count(有引擎分配的实验) / count(实验)` 与
  `count(未处理的 SRM 信号) = 0`。
- **依据**：BR-05、BR-07；SRM 是那个看起来像结果的分配缺陷。

## NFR-006 — 检验力声明完整度
- **目标 (A)**：已开始的实验中，100% 有预先声明的效应量与样本量。
- **公式**：`count(带已声明样本量而开始的) / count(已开始)`。

## NFR-007 — 护栏覆盖率
- **目标 (A)**：100% 的实验声明至少一个护栏指标。
- **公式**：`count(带护栏的实验) / count(实验)`。
- **依据**：BR-07；没有护栏时，被牺牲掉的指标是不可见的。

## NFR-008 — 决策规则纪律
- **目标**：100% 的实验在结果可见**之前**记录了决策规则。
- **公式**：`count(在第一次偷看前记录了规则的) / count(实验)`。

## NFR-009 — 同意强制完整度
- **目标**：100% 的激活检查同意状态，100% 的采集检查它。
- **公式**：两个比率，**分别**上报：`检查同意的激活 / 激活` 与
  `检查同意的采集 / 采集`。
- **依据**：BR-11；一个合并的数字会掩盖是哪个边界缺失。

## NFR-010 — 快照保真度
- **目标**：100% 的活动使用某时刻的成员快照。
- **公式**：`count(带快照的活动) / count(活动)`。

## NFR-011 — schema 变更前置时间
- **目标 (A)**：≥ 95% 的 schema 变更在客户端首次发出之前被声明。
- **公式**：`count(declared_before_first_emit = true 的变更) / count(schema 变更)`。

## NFR-012 — 导出的 schema 版本覆盖率
- **目标**：100% 的导出事件携带 schema 版本。
- **公式**：`count(带版本的导出) / count(导出)`。

## 固定公式

| 量 | 定义 |
|---|---|
| **已声明的 schema** | 一个其 schema 与版本在首次发出**之前**就存在于注册表中的事件 |
| **连接键** | 一次合并所用的匿名标识符或设备标识符；只删档案而留下它，会允许重新识别 |
| **派生事实** | 人群成员资格、漏斗步骤、归因信用——任何从身份图计算出来的东西 |
| **描述性结果** | 一个漏斗、人群、留存或归因输出；显式地不是因果估计 |
| **因果结果** | 仅指实验的效应估计，且在样本量、SRM、护栏、保留组与预先声明的决策规则之下 |
| **按目的限定的同意** | 按目的记录的同意状态，在采集处与激活处被检查 |
| **快照** | 某个时间戳上解析出的分群，不是实时视图 |

> ⚠️ ASSUMPTION — 每一个 `(A)` 目标都是策略。本仓库不主张这些数字来自基准、
> 法规或某个部署。
