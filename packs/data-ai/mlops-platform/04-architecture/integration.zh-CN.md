# 04 · 集成

> 与平台相邻系统之间的集成契约。ID 保持稳定；每个
> 流程都可追溯至需求和规则。
>
> ⚠️ ASSUMPTION — 接口选择和协议属于方案包设计。

## I. 集成点

| ID | 邻接系统 | 方向 | 目的 |
|---|---|---|---|
| **I-01** | **数据平台/仓库** | 入站 | 在契约约束下提供特征和标签 |
| **I-02** | **特征源（批处理和流式）** | 入站 | 时间点值 |
| **I-03** | **训练基础设施** | 出站 | 运行受版本绑定约束 |
| **I-04** | **服务运行时** | 出站 | 读取模型注册中心中已固定的版本 |
| **I-05** | **消费预测的应用** | 出站 | 推理与解释请求 |
| **I-06** | **CI/CD 与制品仓库** | 双向 | 代码和容器来源性质 |
| **I-07** | **身份与访问管理** | 入站 | 谁可以晋级、谁可以提供服务 |
| **I-08** | **文档/披露渠道** | 出站 | 在需要时提供治理制品 |
| **I-09** | **实验跟踪/模型存储** | 任一方向 | 可以是平台自有或厂商提供；作为存储使用，而非权威来源 |

## F. 内部流程

### F-01 — 实验
1. 将代码提交、数据快照和特征定义**作为一个整体固定**后启动运行
   （BR-01）。
2. 特征存储为该版本绑定提供时间点值。
3. 该运行进行训练，并**按分片**记录评估指标（BR-02）。

### F-02 — 注册与审批
1. 注册制品及其版本绑定。
2. 记录风险等级（BR-03）。
3. 由具名主体批准，以分片评估作为所引证据，并写入审批记录
   （BR-04）。
4. 生命周期状态从已注册转为已审批。

### F-03 — 服务
1. 服务运行时**仅从模型注册中心**读取已审批版本（BR-05）。
2. 配置灰度发布和影子发布分流。
3. 回滚会将服务指针设置为此前曾用于服务的版本绑定——这是选择，而不是
   重建（BR-06）。

### F-04 — 监控与响应
1. 在线上流量上运行漂移检测（BR-07）。
2. 将该发现归类为四种类型之一（BR-08）。
3. 保留该发现，并记录响应——回滚、重新训练或下线退役——同时引用该发现。

### F-05 — 解释
1. 对一项预测提出质疑。
2. 血缘信息依据其自身记录作答：模型版本、特征值、上游行、源系统、时间、
   转换（BR-09）。
3. 答案以查询结果而非图表的形式返回。

### F-06 — 下线退役
1. 某个版本在记录了相应依据和具名主体后被下线退役（BR-10）。
2. 由于该版本仍可能在提供服务，其版本绑定在**声明的保留期内保留**
   （BR-11）。

## 失败模式契约

| 集成 | 必须采用的失败模式 |
|---|---|
| **I-01 数据平台** | 契约不可用时降级为*未知*，绝不采用默认值。特征中的静默默认值，正是本方案包要防止的静默故障 |
| **I-02 特征源** | 延迟到达的值会连同其观察时间戳和可用时间戳一并记录，从而确保事后信息绝不会泄漏到时间点计算中 |
| **I-03 训练** | 训练失败就是运行失败，而不是仅完成部分版本绑定的模型。版本绑定要么完整，要么该运行不予注册 |
| **I-04 服务** | 模型注册中心不可用会阻断晋级；服务运行时保留其当前版本，而不是回退到未知版本 |
| **I-06 CI/CD** | 构建通过绝不等于晋级。BR-04 明确规定，CI 作业成功不构成审批 |
| **I-09 模型存储** | 如果使用厂商存储，平台模型注册中心仍是生命周期状态的权威来源；该存储是一个组件，而不是准入门禁 |

> 其模式是：集成不可用时，外部路径会降级并记录为*未知*——绝不作假设，也绝不采用默认值。晋级是例外，它采用故障关闭（fail-closed）方式（BR-05），因为在未知版本上回退服务会使模型注册中心失去意义。

## 模型注册中心契约（每个消费者都必须接受）

| 方面 | 契约 |
|---|---|
| **单一权威来源** | 只有模型注册中心可以写入生命周期状态 |
| **生产环境读取** | 服务运行时只从模型注册中心读取版本，不得从其他任何位置读取 |
| **审批** | 具名主体作出并引用证据的审批记录，绝非 CI 结果 |
| **版本绑定完整性** | 版本若无可解析的版本绑定，则不可注册 |
| **回滚** | 对指针进行选择，受 NFR-004 约束 |

> 无法接受全部五项要求的消费者并未将模型注册中心用作准入门禁；
> 而是在将其用作目录，这正是未注册模型进入生产环境并成为常态的
> 原因。
