# 02 · 非功能需求

> 可度量的目标。**标注 `(A)` 的数值目标是策略假设，不是事实**——记录下来是为了
> 能被锁定、争论和修改；它们的依据见
> [`../SOURCES.md` §4](../SOURCES.md)。
>
> 公式被固定下来，以便任何一方都能复算出同一个数字。没有公式的目标只是一个
> 愿望。
>
> `verification: unverified` —— 目标属于方案包设计。

## NFR-001 — 指标定义复用率
- **目标 (A)**：≥ 70% 的指标被一件以上制品使用。
- **公式**：`count(被 >1 件制品使用的指标) / count(指标)`。
- **依据**：语义层要么是共享的，要么就是复制粘贴。这是唯一能把这二者区分开的
  数字。

## NFR-002 — 重复定义
- **目标**：同名但语义不同的配对为 0。
- **公式**：`count(同名且定义不同的分组) = 0`。
- **依据**：连接键缺失的可检测症状（BR-01）。

## NFR-003 — 权限覆盖率
- **目标**：100% 的数据集带语义层 RLS/CLS 规则；100% 的查询界面求值它们。
- **公式**：`count(带规则的数据集) / count(数据集)` 与
  `count(执行求值的界面) / count(界面)`。
- **依据**：BR-03、BR-10——权限要么集中，要么就是装饰。

## NFR-004 — 语义层求值覆盖率
- **目标**：在语义层之外被服务的查询为 0。
- **公式**：`count(在层之外被回答的查询) = 0`。
- **依据**：BR-08；一个绕过该层的嵌入会把整套访问控制设计变成装饰。

## NFR-005 — 打开时的查询新鲜度
- **目标 (A)**：p95 ≤ 该制品的模型契约窗口。
- **公式**：在打开时取底层模型的 `now - data_ts` 的 p95。

## NFR-006 — 认证覆盖率
- **目标 (A)**：≥ 80% 的*被消费*制品是已认证的。
- **公式**：`count(被消费且已认证的制品) / count(被消费的制品)`。
- **依据**：BR-05——在**被消费**的制品上度量，因为「所有建过的东西里已认证的
> 占比」并不是要紧的那个性质。

## NFR-007 — 晋升周期时间
- **目标 (A)**：从提交到发布或拒绝的 p95 ≤ 5 个工作日。
- **公式**：`decision_ts - submit_ts` 的 p95。
- **依据**：BR-05——晋升比「搭一个私人仪表盘」还慢，意味着用户内容永远不会
> 成为已认证内容，而这个划分会退化成一种层级。

## NFR-008 — 晋升拒绝率
- **目标 (A)**：跟踪；若接近零，说明边界没有被执行；若持续上升，说明已认证
  标准不可达。
- **公式**：`count(拒绝) / count(提交)`。

## NFR-009 — 制品陈旧度
- **目标 (A)**：≤ 10% 的被消费制品固定在被取代的模型版本上。
- **公式**：`count(在被取代版本上的制品) / count(被消费的制品)`。
- **依据**：BR-09——陈旧制品是一个无人拥有、却会被信任的制品。

## NFR-010 — 定义变更的影响可见性
- **目标**：100% 的模型版本发布都附带一份影响报告。
- **公式**：`count(附带影响报告的发布) / count(发布)`。
- **依据**：BR-06、FR-011——没人预见到的变更，正是「并未真正共享的共同词汇」
> 的失败模式。

## NFR-011 — 跨界面可见延迟
- **目标 (A)**：从制品状态变更到其他所有界面可见的 p95 ≤ 5 秒。
- **依据**：度量核心是共享的，而不是被分叉了。

## NFR-012 — 自助分析成功率
- **目标 (A)**：≥ 90% 的自助查询返回行或一个明确的空结果，而不是报错。
- **公式**：`count(返回行或空的查询) / count(自助查询)`。
- **依据**：探查必须可行，否则这个平台只是一份目录，而不是一件工具。

## 固定公式

| 量 | 定义 |
|---|---|
| **可连接的指标** | 两个指标可比 ⇔ 它们按一个已声明的连接键相连（BR-01） |
| **RLS 规则求值** | 语义模型中的一条规则，带着查询中的身份上下文被求值——绝不是呈现时过滤 |
| **新鲜度** | 底层模型的 `now - data_ts`，对照模型声明的契约窗口 |
| **认证状态** | `f(模型契约状态, 流水线状态, 制品负责人, 制品版本)`——计算得出，绝不手工标注 |
| **制品陈旧度** | 制品固定的模型版本已被取代 |
| **被消费的制品** | 在度量窗口内至少被打开或渲染过一次制品 |

> ⚠️ ASSUMPTION — 每一个 `(A)` 目标都是策略。本仓库不主张这些数字来自基准、
> 法规或某个部署。
