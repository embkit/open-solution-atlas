# AGENTS.md — Telecom BSS/OSS (L1)

L1 brief. At L2: keep the BSS (commercial) vs. OSS (resource/fulfillment)
boundary explicit as an integration contract, never blurred; the commercial
product catalog and the technical/resource catalog are distinct models joined
by a specification, not duplicated; adopt TM Forum ODA component and TMF Open
API family vocabulary as the normative interface language; order
decomposition from customer order to service order to resource order must be
traceable end-to-end; rating/billing events are immutable and reconcilable
against both the order and the inventory; GDPR-class privacy applies to
subscriber data with retention and erasure rules stated per data class.
