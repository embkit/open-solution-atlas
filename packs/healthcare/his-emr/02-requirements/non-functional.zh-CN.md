# 02 · 非功能需求

> 可度量的目标。**标记为 `(A)` 的数值目标属于政策假设，而非事实**——记录在案，以便锁定、论证和变更；其依据见 [`../SOURCES.md` §4](../SOURCES.md)。
>
> 公式已锁定，以便任何一方都能复算出同一数值。没有公式的目标只是一种愿望。
>
> `verification: unverified`——这些目标属于方案包设计。

## NFR-001 — 已签署文书修订完整性
- **目标**：100%。对已签署临床文书的原位编辑为零。
- **公式**：`count(signed documents edited in place) = 0`。
- **依据**：这是一项不变量（BR-07），而非服务水平。已签署的病程记录是某一时刻思考内容的证据。

## NFR-002 — 已签署文书补录率
- **目标 (A)**：持续跟踪；补录率上升表明上游的补录编写存在可用性缺陷，而非文档问题。
- **公式**：`count(addenda) / count(signed documents)`，按周期计算。

## NFR-003 — 拆分能力
- **目标**：100% 的合并均可拆分，且每次拆分都会传播到所有关联的临床事实。
- **公式**：`count(merges that can be reversed with propagation) / count(merges)`。
- **依据**：这是一项不变量（BR-05）。

## NFR-004 — 重复档案解决积压
- **目标 (A)**：从提出重复档案标记起，到完成主索引核对或明确延期，p95 ≤ 48 小时。
- **公式**：`resolved_ts - raised_ts`，按 p95 计算。

## NFR-005 — 悬空医嘱
- **目标**：最终缺少结果、处置或复核中任一项的医嘱为 0。
- **公式**：`count(orders missing any of the three) = 0`。
- **依据**：这是一项不变量（BR-09）。在有人核查之前，悬空医嘱与已完成医嘱无法区分。

## NFR-006 — 医嘱至结果闭环率
- **目标 (A)**：在规定窗口内达到闭环的医嘱占比 ≥ 99%。
- **公式**：`count(orders closed within window) / count(orders)`。

## NFR-007 — 编码版本覆盖率
- **目标**：100% 的已编码事实均携带其编码体系**和**版本。
- **公式**：`count(coded facts with system and version) / count(coded facts)`。
- **依据**：这是一项不变量（BR-11）。否则，下游重新映射将无法解释，历史数值也无法复现。

## NFR-008 — DICOM 边界完整性
- **目标**：100% 的影像检查以带引用的 DICOM 对象形式保留；其对象被丢弃并以派生表取代的检查为 0。
- **公式**：`count(studies with retained objects) / count(studies)`。
- **依据**：BR-10——分解会不可逆地丢失信息。

## NFR-009 — 临床与收费差异率
- **目标 (A)**：按周期、按功能跟踪，并提供书面记录的解决路径。
- **公式**：`count(divergences reported) / count(encounters)`。
- **依据**：BR-12。出现差异在预期之内；但经*编辑的*临床病历并非如此。该指标衡量的是已作解释的案例，而非问题案例。

## NFR-010 — 临床病历编辑完整性
- **目标**：因收费争议而发生更改的临床事实为 0。
- **公式**：`count(clinical changes attributed to billing) = 0`。
- **依据**：这是一项不变量（BR-12、ADR-0005）。这是本方案包的首要规则，也是其度量方式。

## NFR-011 — 紧急访问率
- **目标 (A)**：紧急访问占记录访问次数的 < 1%，且**呈下降趋势**。
- **公式**：`count(break-glass accesses) / count(record accesses)`。
- **依据**：BR-14——按定义，紧急访问属于例外情况。趋势比占比水平更重要：比率上升意味着正常访问路径已失效。

## NFR-012 — 紧急访问复核完成率
- **目标**：100% 的紧急访问在规定窗口内完成复核。
- **公式**：`count(reviewed within window) / count(break-glass accesses)`。

## NFR-013 — 访问审计完整性
- **目标**：100% 的记录访问均带有可归责的行为主体、访问依据和时间戳。
- **公式**：`count(attributable accesses) / count(accesses)`。
- **依据**：BR-13、BR-14；也是分级保护控制措施的证据基础。

## NFR-014 — 各删除目标位置的删除完成率
- **目标**：100% 的获准执行请求在每个目标位置均有记录结果。
- **公式**：`count(requests with a recorded outcome per destination) / count(requests)`。
- **依据**：BR-16——未记录结果的目标位置并未删除。

## 锁定公式

| 量化项 | 定义 |
|---|---|
| **已签署文书** | 署名与签署是彼此独立的属性；签署人、时间戳和确认声明均予以记录 |
| **补录** | 具有明确作者归属、带时间戳并引用原始文档的更正；原始文档绝不编辑 |
| **闭环** | 医嘱具备结果、处置**和**复核——必须三者俱全，否则即为悬空医嘱 |
| **已编码事实** | 携带其代码、其**编码体系**及该体系**版本**的诊断或诊疗操作 |
| **临床事实** | 临床病历是临床事实的权威依据；收费/结算记录是收费项目的权威依据 |
| **紧急访问** | 正常授权范围之外的访问；须记录日志、说明理由并接受复核 |
| **删除目标位置** | 主记录、副本、缓存、日志、派生数据集——每个目标位置均记录各自的结果 |

> ⚠️ ASSUMPTION — 每个 `(A)` 目标均属于政策。本仓库不主张这些目标来自基准、法规或实际部署。
