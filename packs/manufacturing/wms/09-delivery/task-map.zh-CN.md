# 09-delivery · 可由智能体执行的任务地图

任务按每次聚焦的智能体改动切分，并各自带一个验证钩子。ID 采用 `T-xx`；每条任务
映射到一个里程碑以及 FR/NFR/CTL/AC 编号。逐个里程碑执行；**不要跳过验证钩子**。
T 编号与任务卡 1:1 对应。

## M0 —— 基础：事件日志 + 库存骨架

- **T-01** 仅追加的 StockEvent 存储：有序、不可变、哈希链式、先落盘再确认。验证：
  篡改尝试被拒绝；重放是确定性的。[ADR-0002, NFR-009, CTL-05, AC-N09]
- **T-02** `StockPosition` 折叠投影 + 持续对账作业。验证：在种子序列上
  fold(log) == 投影；出现分歧即告警。[ADR-0002, AC-N09]
- **T-03** 库存唯一写入者内部 API（C-25）：提交前校验 BR-01 货位标识与 BR-02
  非负约束。验证：非法货位变更与负数尝试均以事务方式拒绝。[NFR-008, AC-N08]
- **T-04** 原子预留原语（C-23）：在 available/version 上做比较并置；软/硬生命周期
  并带过期释放。验证：并发测试框架保证每个单元最多被授予一次。
  [FR-019, BR-05, AC-019]
- **T-05** IAM：OIDC bearer 认证、RBAC 角色、所有者范围的 RLS、特权操作审计。
  验证：跨所有者的读写探测被拒绝。[NFR-011, CTL-06, AC-N11]

## M1 —— 主数据与 GS1

- **T-06** 仓库/区域/库位模型，含容量与容量上限校验（C-01）。验证：超容量的下级
  被拒绝。[FR-001, AC-001]
- **T-07** SKU 主数据：包装层级、计量单位换算、控制标志（C-02）。验证：计量单位
  往返一致；批次标志会拦截未标记的收货。[FR-002, AC-002]
- **T-08** 所有者模型 + 隔离策略（C-03）。验证：每一行新建数据都带所有者；门户
  过滤器被强制执行。[FR-003, BR-13, AC-003]
- **T-09** 带生效日期配置的策略/规则引擎（C-04）；在任务/订单上记录
  `strategy_version`。验证：仅改配置即可改变分配，无需部署；在途任务仍保持其
  版本。[FR-004, ADR-0004, AC-004]
- **T-10** GS1/AI 解析器：GTIN/SSCC/批次(10)/序列号(21)/有效期(17)/数量/重量，
  校验位 + 拒绝重复（C-05）。验证：语料库包含错误校验位的情形。
  [FR-005, CTL-02, AC-005]

## M2 —— 入库与上架

- **T-11** ASN 接入 + 未结采购订单校验、月台关联、按业务键幂等（C-06）。验证：
  未知采购订单 → 422；重复投递为空操作。[FR-006, NFR-010, AC-006]
- **T-12** 收货：盲数/预期数、多收/少收/损坏、容差冻结（C-07）。验证：在 ±tol
  范围内被接受；超出容差 → 差异冻结。[FR-007, BR-11, AC-007]
- **T-13** SSCC Handling Unit 层级构建 + 标签（C-08）。验证：每层 SSCC 唯一且
  有效；缺少批次/有效期会拦截受控品项。[FR-008, CTL-02, AC-008]
- **T-14** 待检路由 + 处置（C-09）。验证：待检库存绝不会出现在分配候选中。
  [FR-009, CTL-03, AC-009]
- **T-15** 定向上架生成（BR-03/04）+ 对库位+LP 的扫码确认（C-10）。验证：扫错
  库位被拦截；正确扫码 → 转为可用。[FR-010, BR-08a, AC-010]
- **T-16** 上架确认时的收货出库事件（不含计价）。验证：恰好一个事件；没有金额
  字段。[FR-011, ADR-0001, AC-011]

## M3 —— 库内与库存管控

- **T-17** 库存状态流转（可用/锁定/隔离/冻结/报废）（C-11）。验证：冻结品项不再
  出现在下一次分配集合中。[FR-012, BR-01, AC-012]
- **T-18** 遵守 FIFO/FEFO 且受有效期拦截的补货（C-12）。验证：先占用最早到期的
  库存；被拦截的批次被排除。[FR-013, BR-06, AC-013]
- **T-19** 移库/调拨任务，带 `in_transit_intra` 结算（C-13）。验证：数量在端到端
  过程中不被重复计算。[FR-014, BR-01, AC-014]
- **T-20** 冻结/暂停 + 处置 + 召回追溯（C-14）。验证：被冻结批次不可分配/发货；
  追溯列出来源与去向。[FR-015, P-07, AC-015]
- **T-21** 配套/增值服务/换包装，含部件消耗与谱系（C-15）。验证：同样的预留与
  事件不变量适用。[FR-016, AC-016]

## M4 —— 出库与波次

- **T-22** 订单接入 + 校验、波次资格判定（C-16）。验证：非法订单被拒绝或排队，
  合法订单具备波次资格。[FR-017, AC-017]
- **T-23** 波次构建 + **原子**软→硬分配 + 拣货任务生成（C-17）。验证：部分失败
  回滚整批下发；并发下零超卖。[FR-018, FR-019, BR-05, AC-018, AC-019, AC-N02]
- **T-24** 拣货方式 + 扫码校验确认 + 少拣再分配/缺货订货（C-18）。验证：扫错
  库位/品项被拦截；缺货改道。[FR-020, BR-08b, AC-020]

## M5 —— 打包、发运与退货

- **T-25** 打包校验（受管控货物）+ 装箱/称重/增值服务（C-19）。验证：受管控 SKU
  缺少强制序列号会拦截发货。[FR-021, BR-08c, AC-021]
- **T-26** 装载与发货单核对 + 发运确认 → 库存扣减、货物出库、出库 ASN（C-20）。
  验证：BR-12 闸门被强制执行；恰好一个货物出库事件。
  [FR-022, BR-08d/12, AC-022]
- **T-27** 退货接入 + 与发运单匹配 + 处置路由（C-21）。验证：只有合格品可退回
  可用状态。[FR-023, AC-023]

## M6 —— 盘点与对账

- **T-28** 盘点计划（ABC + 触发条件）+ 盲盘录入（C-26）。验证：账面数量被隐藏；
  盘点中的库位被排除在上架候选之外。[FR-024, BR-09, AC-024]
- **T-29** 差异容差 → 复盘 → 职责分离批准的调整 → 过账 ERP（C-27）。验证：拒绝
  自我审批；记录调整前/后与原因。[FR-024, BR-10, CTL-04, AC-024]

## M7 —— 自动化边界与追溯

- **T-30** 设备网关：任务下发 + 生命周期/故障事件接入、白名单通道（C-28）。验证：
  未列入白名单的目标被拒绝；设备事件只驱动任务状态。
  [FR-025, ADR-0003, CTL-07, AC-025, AC-N12]
- **T-31** 自动化故障回退到人工，复用 SM-3，恢复时只发生一次变更
  （C-28/C-22）。验证：杀掉网关 → 人工恰好完成一次；恢复不产生重复。
  [FR-026, AC-026]
- **T-32** 批次/序列号追溯 + 对齐 EPCIS 的导出（C-29/C-30）。验证：供应商批次 →
  LP → 移动 → 发运可解析并可导出。[FR-027, CTL-01, AC-027]
- **T-33** 异常工作台：类型、责任人、账龄、建议、深链、一键转人工（C-31）。验证：
  FR-028 的每种异常类型都出现。[FR-028, AC-028]

## M8 —— 加固：性能、高可用/灾备、安全

- **T-34** 性能测试台与性能剖面：扫码时延（NFR-001）、分配（NFR-002）、数据量
  （NFR-003）、吞吐（NFR-004）。验证：AC-N01..N04 在参考数据集与 5 亿事件
  数据集上测得。[NFR-001..004]
- **T-35** 高可用 + 故障切换 + 事件日志恢复演练。验证：RTO ≤ 30 分钟 /
  RPO ≤ 5 分钟；已提交事件零丢失。[NFR-005, NFR-006, AC-N05, AC-N06]
- **T-36** RF 离线队列 + 重连后的幂等对账。验证：≥ 5 条排队确认各自恰好入账
  一次。[NFR-007, NFR-010, AC-N07, AC-N10]
- **T-37** 安全加固：RLS/职责分离反向用例集、IT↔OT 白名单测试、可观测性告警
  （超卖/负数/未处理设备/SLA）。验证：AC-N11/N12/N13 通过，跨所有者与超卖
  告警触发。[NFR-011, NFR-012, NFR-013, CTL-04, CTL-06, CTL-07]
- **T-38** 本地化与标签：多计量单位呈现、en/zh-CN、时区、GS1 标签尺寸与回扫。
  验证：在配置的打印机集群上通过 AC-N14。[NFR-014, AC-N14]
