# 09-delivery · 里程碑

增量推进，每个里程碑均可独立演示。范围涵盖 Must/Should 能力（capability-map 01–07）；受监管/保税/冷链叠加层位于 `variants/`，绝不阻断核心里程碑。每个里程碑均列明用于退出该里程碑的 AC 验证项。

| M | 名称 | 成果（可演示） | 退出条件 |
|---|---|---|---|
| M0 | 基础：事件日志 + 库存骨架 | 仅追加的 StockEvent 存储，采用哈希链；`fold(log)==StockPosition` 对账作业；唯一写入方内部路径（C-25）；RLS 骨架 | fold 重放可复现投影；篡改尝试被拒绝 — AC-N09, AC-N11（部分） |
| M1 | 主数据与 GS1 | 仓库/区域/库位及容量校验；SKU 包装层级/UOM；货主模型；带生效日期的策略配置（ADR-0004）；GS1/AI 解析器 | AC-001..005 |
| M2 | 入库与上架 | ASN 接收与校验；收货清点（盲数/预期数、容差）；SSCC 装卸/物流单元构建；质检移交；定向上架 + 确认；收货过账事件 | AC-006..011 |
| M3 | 库内作业与库存控制 | 状态转换；移动（`in_transit_intra`）；补货（FIFO/FEFO）；冻结/待检、隔离、处置；组套/VAS | AC-012..016 |
| M4 | 出库与波次 | 订单接收/校验；波次构建 + 原子化分配/释放；拣货方式；带扫描控制的拣货确认；重新分配/缺货订单 | AC-017..020, AC-N02 |
| M5 | 打包、发运与退货 | 复核（受控货物）；装箱计算/称重/VAS；装载至装车/发运清单；发运确认 → 发货过账 + ASN；退货处置 | AC-021..023 |
| M6 | 盘点与对账 | ABC 盘点计划 + 触发条件；盲盘；差异容差/复盘；经 SoD 批准的调整；ERP 过账 | AC-024 |
| M7 | 自动化边界与追溯 | 设备任务网关（调度 + 事件）；故障回退到人工操作；符合 EPCIS 的追溯/导出；异常工作台 | AC-025..028, AC-N12 |
| M8 | 加固：性能、高可用/灾难恢复、安全 | 性能配置（NFR-001..004）；高可用/故障切换 + 事件日志恢复（NFR-006）；RF 离线对账（NFR-007）；RLS/SoD/IT-OT 测试；可观测性告警 | AC-N01/N03/N04/N05/N06/N07/N08/N10/N13/N14 |

依赖关系：M0 → 全部（事件日志和唯一写入方是关键基础）；M1 → M2..M6；M2 → M3（执行库内作业前必须已有库存）；M4 → M5；M3 完成后 M6 可独立进行；M7 依赖于 M3+M4（任务）和 M0（事件）；M8 最后（需要功能完备的系统才能进行性能分析）。M0 落地后，M1、M6 和 M7-gateway 适配器即可并行运行。
