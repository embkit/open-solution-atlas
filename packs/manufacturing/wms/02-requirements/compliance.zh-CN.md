# 02-requirements / 合规控制

控制要求 `CTL-01..CTL-07`，可追溯至法规/标准及需求。核心方案包实现审计级控制；适用于制药行业的电子签名/验证深度属于变体。

| ID | 控制 | 要求/机制 | 追溯 |
|---|---|---|---|
| **CTL-01** | 完整移动可追溯性 | 每次数量变更均关联业务单据（ASN/PO/订单/盘点）、任务、操作员、设备和时间戳；批次/序列号可导出正向/反向追溯 | ISO 9001 8.5.2; GS1 EPCIS; FR-027, NFR-009, ADR-0002 |
| **CTL-02** | GS1 标识完整性 | 条码/标签及物流单元层级符合 GTIN/SSCC/AI；解析过程须经验证；拒绝重复/非法 SSCC | GS1; FR-005, FR-008 |
| **CTL-03** | 状态/待检强制执行 | 待质量检查/冻结/隔离/到期阻断的库存从系统层面不可分配；必须经过处置方可更改状态 | ISO 9001; GDP/FEFO（变体）; FR-009, FR-015, BR-06 |
| **CTL-04** | 调整的职责分离 | 经办人 ≠ 审批人；按价值/数量实行分级审批；记录调整前/后值、原因代码和审批人；调整过账至 ERP | ISO 9001 7.5; internal control; FR-024, BR-10 |
| **CTL-05** | 不可变且可检测篡改的审计记录 | 仅可追加的事件；应用角色不得直接更新或删除底层记录；持久且有序；保留期策略可配置 | ISO 9001; Annex 11/Part 11（变体）; NFR-009, ADR-0002 |
| **CTL-06** | 访问控制与货主数据隔离 | 基于角色的访问控制（RBAC）+ 按货主划分的行级安全（RLS）、特权操作日志记录、身份认证（受监管变体中的管理员使用多因素身份验证）、定期访问审查 | ISO/IEC 27001; 等保2.0（变体）; NFR-011 |
| **CTL-07** | IT/OT 安全边界 | WCS 集成须经身份验证并列入允许清单，且通过受控通道接入；不得直接写入控制指令；设备事件须经验证 | IEC 62443; NFR-012, ADR-0003 |

## 延后至变体的控制项（已声明，非核心）

- **电子签名/记录审查**（21 CFR Part 11、GMP Annex 11）：经签署的处置决定、记录锁定、基于例外进行审查 → `regulated-edhr/cold-chain` 变体。
- **温度偏离证据与 GDP**：IoT 数据流、因温度偏离而实施的冻结、已校准的探针记录 → `cold-chain` 变体。
- **保税/海关监管库存账册与等保 2.0 控制** → 区域性变体。

> 核心方案包绝不得嵌入法定条文；其编码的是*控制义务*，并将各司法辖区的具体要求留给变体处理。
