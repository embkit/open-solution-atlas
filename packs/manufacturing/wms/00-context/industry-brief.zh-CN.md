# 00-context / 行业简报 — 仓储管理

## 1. 仓库在价值链中的定位

仓库（或配送中心，DC）是物流网络中的一个节点，货物在此**收货、保管、加工（配套组装/贴标）和发运**。与单纯的库存账本不同，仓库是一项实体作业：劳动力、设备、空间和时间均属稀缺资源，必须像工厂车间一样进行调度。

**仓储管理系统（Warehouse Management System，WMS）**是执行系统，它将入库单据（预先发货通知〔ASNs〕、采购订单、调拨订单和退货）与出库需求（销售订单、STOs、生产拉动）转化为**经核验的实物移动**，并回报每个单元真实的现有量、位置、批次/序列号状态和所有权归属。

WMS 处于三套系统构成的边界内：

```
ERP / OMS / MES                 WMS                         自动化设备 / 承运商
------------------    -------------------------    -----------------------------
财务库存                      实物库存真实状态            仓储控制系统/仓储执行系统（WCS/WES；自动化立体库（AS-RS）、输送机、
订单与规划          ->        入库/出库执行        ->      自动导引车/自主移动机器人（AGV/AMR））、秤、打印机
估值与成本核算                任务、波次、预留            TMS/承运商、包裹标签
```

WMS 不对库存估值，也不规划运输；它确保在库位/批次粒度上 **system stock == physical stock**，并确保正确的单元为正确的订单从月台发出。

## 2. 部署架构类型

同一核心模型适用于四种架构类型；它们的差异在于策略参数、所有权和监管附加要求，而不在于基本移动模型。

| 架构类型 | 主要特征 |
|---|---|
| **制造原材料/在制品（WIP）/成品（FG）仓库** | 与 MES/ERP 紧密集成；向生产线暂存货物（参见 mes 方案包）；批次/序列号血缘关系；成品上架；称重/质量控制（QC）闸门 |
| **零售/电商配送中心** | 高频次波次、拆零拣选、分拣机、增值服务（VAS）、退货（逆向物流）、当日截单时点 |
| **第三方物流（3PL）多货主配送中心** | 同一实体设施内存在多个货主；按货主隔离的库存；按作业活动计费（仓储费/操作费）；货主专属 SOP |
| **冷链/受监管场景** | 温控分区、IoT 越限监控、GMP/待检、强制执行先到期先出（FEFO）、监管链（变体） |

> ⚠️ ASSUMPTION: 核心方案包将货主（owner）建模为一等属性，因此 3PL 架构类型无需采用分叉模式；架构类型差异通过策略规则和变体表达，而非采用各自独立的代码路径。

## 3. 核心运营流程（L1 视图）

1. **入库（Inbound）**：ASN/PO → 月台预约 → 收货与计数 → 标识/贴标（SSCC）→ 待质检（如需）→ 上架 → 库存转为可用状态。
2. **库内（In-warehouse）**：库位/批次管理、移库、从存储区向拣货面补货、冻结/待检、增值服务/配套组装、循环盘点。
3. **出库（Outbound）**：波次规划 → 分配与预留 → 拣货 → 复核 → 发运/装车 → 发货过账，库存扣减。
4. **库存准确性闭环**：循环盘点（ABC）→ 差异 → 经审批且附有原因代码的调整 → 与 ERP 对账。
5. **自动化与设备闭环**：WMS 发出运输/订单任务；WCS/WES 驱动设备执行并回报完成事件。

## 4. WMS 为何具有挑战性（关键张力）

- **并发**：多名拣货员可能同时从同一库位/批次取货。朴素的“先检查后扣减”会导致库存超卖。预留与数量原子变更是强制要求（ADR-0002）。
- **实物库存与财务库存的真实状态**：WMS 负责实物库存；ERP 负责估值。调整必须作为可审计事件流转，绝不能以静默覆盖方式处理（ADR-0001）。
- **策略复杂性**：上架和分配采用规则引擎（先进先出〔FIFO〕、先到期先出〔FEFO〕、固定/浮动库位、区域亲和性、批次定向、体积/重量匹配）。规则因货主/SKU 而异，因此必须由数据驱动。
- **扫描纪律与吞吐量**：每次核验扫描都能提高准确率，但会耗费数秒；系统必须在控制点强制扫描，同时允许在其他位置采用批量扫描/例外确认。
- **自动化异构性**：AS-RS、输送机、AMR 和电子标签拣货设备采用不同协议。WMS 必须依赖稳定的**基于任务**的设备边界，而非厂商动作原语（ADR-0003）。
- **无纸化作业现场**：手持 RF 终端、车载终端和可穿戴设备在 Wi-Fi 不佳时以近似离线方式运行；模型必须能够容忍延迟确认，同时不得重复执行任务。

## 5. 关键绩效与质量指标

| 指标 | 典型目标范围 | 含义 |
|---|---|---|
| 库存准确率（Inventory accuracy） | ≥ 99.5%（受监管场景 ≥ 99.9%） | 系统数据与实盘值对比，按库位/SKU 统计 |
| 拣货准确率 | ≥ 99.9% | 发运时 SKU、数量和批次均正确 |
| 月台至库存可用时长 | 按 SKU 类别以小时计 | 收货 → 可用库位 |
| 订单满足率/准时发运 | ≥ 98% | 在承运商截单前完整履约 |
| 每操作员每小时处理行数 | 因架构类型而异 | 劳动生产率 |
| 空间利用率 | 库位容积/货位数量的百分比 | 布局效率 |
| 循环盘点完成率 | ABC 计划/周期内完成 100% | 控制合规性 |

> 确切的类似 OEE 的衍生指标及其公式精确度在 `01-business/business-rules.md` 中规定（BR 层级）；本章仅界定意图。

## 6. 支撑模型的公共标准

- **GS1** 标识：全球贸易项目代码（GTIN，贸易项目）、系列货运包装箱代码（SSCC，物流单元）、全球位置码（GLN，参与方/位置）、批次（AI 10）、序列号（AI 21）、有效期（AI 17）。
- **GS1 EPCIS** — 用于建模生命周期追溯的事件词汇表（Object/Aggregation/Transaction 事件；何事/何时/何地/为何）。
- ISO 9001 可追溯性；冷链/GMP 变体增加 GDP/附录 11 控制措施。
