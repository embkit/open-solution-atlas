# 00-context / 利益相关方

## 1. 组织

| 组织 | 职责 | 系统关系 |
|---|---|---|
| 仓储运营方 / 第三方物流（3PL） | 运营仓库设施、人员和设备 | 拥有并运营仓储管理系统（WMS） |
| 货主（第三方物流场景） | 拥有库存；制定 SOPs、策略和 SLA | 配置为货主；接收库存报告/账单 |
| 采购方 / 供应商 | 按 PO 交付；提供预先发货通知（ASN） | ASN/EDI 来源 |
| 客户 / 收货方 | 接收发运货物 | ASN/标签/EDI 接收方 |
| 承运商 / 第三方物流运输 | 运输、装车/发运清单、跟踪 | 标签/清单/跟踪集成 |
| 质检 / 质量部门 | 验收/拒收到货，解除冻结 | 驱动待检与处置 |
| 财务 / 库存控制 | 对实物与账面进行对账，批准调整 | 消费调整/报表事件 |
| 生产计划（制造） | 请求物料备货，报告成品（FG） | 与 MES/ERP 集成 |
| IT / 自动化工程 | 负责仓储控制系统/仓储执行系统（WCS/WES）、设备及接口的运行 | 设备边界责任方 |
| 监管机构 / 审计人员 | GMP、海关、食品/冷链审计 | 只读证据/电子记录 |

## 3. 作为参与者的外部 / 上游下游系统

- **ERP**：采购订单、STO、销售订单、物料/估值主数据；消费收货 / 发货过账及调整事件。
- **OMS/电子商务**：订单来源、截单时间、交付承诺。
- **MES（制造）**：备料请求、物料消耗、成品收货（边界与 `mes` 方案包一致——参见关于备料状态真实性的开放问题）。
- **TMS/承运商平台**：运输委托、装车/发运清单、包裹标签、跟踪。
- **仓储控制系统/仓储执行系统（WCS/WES）、自动化立体库（AS-RS）、输送机/分拣机、自动导引车/自主移动机器人（AGV/AMR）、秤具、打印机、RFID 闸门**。
- **园区管理/月台门调度**（可能为模块或外部系统）。

## 4. 参与者目标（主要）

- 拣货员：将行走降至最低、任务无歧义、避免“库位缺货”。
- 主管：确保波次赶上承运商截单时间；快速处理异常。
- 库存管理员：不存在无法解释的差异；每项调整都有原因、审批人和审计轨迹。
- 货主：准确且按货主隔离的可见性，以及装卸凭证。
- 经理：每工时吞吐量、空间利用率、准确性目标。
