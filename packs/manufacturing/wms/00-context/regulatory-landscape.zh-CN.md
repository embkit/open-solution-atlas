# 00-context / 监管与标准格局

> 仓储管理系统（WMS）的核心主要依据**标识与可追溯性标准**进行治理，而非受大量成文法约束。行业特定监管（制药/食品/冷链、海关/保税）通过变体引入。

## 1. 标识与数据交换（全球）

| 标准 | 适用范围 | 方案包影响 |
|---|---|---|
| **GS1 通用规范** | GTIN、GLN、SSCC、AI 数据（批次 `10`、序列号 `21`、有效期 `17`、数量、重量） | 标签/条码模型、物流单元层级。版本需对照 ref.gs1.org 上的当前发布版确认 |
| **GS1 SSCC** | 系列货运包装箱代码——物流单元唯一使用的 GS1 键；AI **(00)** | 入库/出库托盘/纸箱所用的托盘/容器标签标识符 |
| **GS1 EPCIS 2.0 + CBV 2.0**（2022 年 6 月获批准） | 事件词汇表（Object/Aggregation/Transaction/Association；业务步骤/处置）；JSON/JSON-LD + REST 采集/查询 | 用于追溯和合作伙伴交换的规范化事件模型 |
| **GS1 EPC 标签数据标准（TDS）2.3.0**；**Gen2 UHF 空中接口 3.0.1** | EPC 标识符和 RFID 标签数据 | RFID 采集通道 |
| EDI / UN/EDIFACT（**DESADV**、ORDERS、IFTMIN）及其 GS1 **EANCOM** 子集；ANSI X12 **856**（ASN）、**850**（PO） | B2B 单据 | 预先发货通知（ASN）/订单/装车发运清单接口（协议中立） |

## 2. 质量与可追溯性管理

| 框架 | 适用范围 | 方案包影响 |
|---|---|---|
| **ISO 9001:2015**（8.5.2 标识与可追溯性、8.5.4 保留、8.7 不合格输出控制、7.5 文件化信息） | QMS 可追溯性、记录控制、不合格输出控制 | 批次/序列号血缘关系、保留记录、状态/待检控制 |
| **ISO 22005 / HACCP**（食品） | 饲料/食品可追溯性 | 批次流向、召回支持（变体） |
| **EU GDP**（2013/C 343/01） | 药品良好分销规范 | 先到期先出（FEFO）、温度、监管链（冷链/制药变体） |
| **EU GMP 附录 11** | 计算机化系统、电子记录/电子签名 | 审计追踪、访问控制、验证（受监管变体） |
| **US FDA 21 CFR Part 11** | 电子记录/签名 | 电子签名、不可变审计追踪（受监管变体） |

## 3. 信息安全与韧性

- **ISO/IEC 27001:2022**（附录 A — A.5.15–A.5.18 访问控制/身份、
  A.8.2 特权访问权限、A.8.15 日志记录、A.8.24 密码技术使用、
  A.5.33 记录保护、A.8.13 备份）— 面向库存/商业数据的 ISMS 控制措施。
- **IEC 62443**（当 WMS 接入 OT/自动化网络时）— **62443-3-2**
  （划分为区域与通道）、**62443-3-3**（系统安全要求）、
  **62443-4-2**（组件安全要求）；IT↔OT 设备边界属于安全边界。
- **等保 2.0（MLPS 2.0，中国）** — GB/T 22239-2019；面向中国的部署；
  在 `xinchuang-cn` 变体中处理，不内置于核心。

## 4. 领域/区域运营监管

- **海关/保税仓储（海关保税）**：特殊库存状态、独立账簿、受监管的货物移动——
  建模为库存*状态/所有权*标志 + 报告；当地具体要求在变体中处理。
- **度量衡/贸易**：经校准的秤、法定贸易用计量单位。
- 危险品（ADR/IATA-DGA）仓储隔离规则——由属性驱动的货位兼容性
  （危险品类别），核心中不包含法规原文。

## 5. 审计期望（必须具备哪些证据）

1. 每一次数量变更都必须能够追溯到 **业务单据 + 任务 + 操作员 +
   时间戳 + 设备**（事件溯源式移动——ADR-0002）。
2. 库存调整必须具备原因代码、审批以及调整前/后的数值。
3. 批次/序列号的正向与反向追溯（哪个入库批次流向了哪次出库发运）
   必须可导出，以支持召回。
4. 访问控制和职责分离（柜台人员不能自行批准大额调整）。
5. 记录保留期限（由变体定义），以及受监管变体中的不可变审计追踪。
