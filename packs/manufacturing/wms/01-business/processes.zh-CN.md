# 01-business / 核心业务流程

涵盖参与方、触发条件、前置条件、主流程、异常路径和结果的端到端流程。ID 为 `P-01..P-08`。

---

## P-01 从预先发货通知（ASN）到可用库存的入库流程

- **触发条件**：收到预先发货通知（EDI 856 / API），或预计采购订单（PO）到货。
- **参与方**：收货员、质检员、上架操作员、系统。
- **前置条件**：采购订单（PO）/预先发货通知（ASN）与供应商主数据有效；月台日历已开放。

1. 承运商在闸门签到；主管分配月台门/预约。
2. 收货员打开预先发货通知；执行盘点——盲盘或与预期数量核对。
3. 扫描/识别每个装卸/物流单元；构建系列货运包装箱代码（SSCC）托盘/容器标签（LP）层级（托盘 → 纸箱 → EA）；在需要时采集批次/序列号/有效期。
4. 针对预先发货通知行记录多收/短收/损坏；进入差异处理流程。
5. 如需质检 → 单元进入隔离区并标为**待质检**；否则直接进入可用、待上架状态。
6. 系统通过策略（BR-03）计算上架位置；创建任务。
7. 操作员扫描库位 + LP 确认上架；库存变为可用。
8. 将收货事件过账至 ERP（实物收货；估值归属 ERP — ADR-0001）。

- **异常**：未知最小存货单位（SKU）/批次 → 异常库位 + 主管处理；预先发货通知中的交付超出容差 → 冻结以供决策。
- **结果**：库存位于库位，状态为可用/隔离，收货已过账，并建立供应商批次 → 内部 LP/批次 的追溯链路。

## P-02 定向上架

- **触发条件**：已收货且等待上架的 LP。
- **规则**：BR-03（策略）、BR-04（库位兼容性）、容量。
- 流程：对候选库位评分（区域亲和性、SKU 的固定库位、符合重量/高度/危险品/温度要求的最近可用库位） → 分配任务 → 扫描确认（系统可建议库位；若允许，操作员可提出替代库位并说明原因）。
- **结果**：LP 已定位；存储区/拣货位占用量已更新。

---

## P-03 补货至拣货位

- **触发条件**：拣货位数量 ≤ 最小值，或波次需求超过拣货位库存，或计划补货。
- 流程：从存储区批次计算所需数量（遵循先进先出（FIFO）/先到期先出（FEFO）及批次状态） → 创建移动任务 → 从存储区库位确认移出、向拣货位确认移入 → 存储区数量扣减，拣货位数量增加（保留净货主归属/批次）。
- **结果**：在已下发波次期间，不会有拣货任务被送往空拣货位。

---

## P-04 波次规划、分配与拣货

- **触发条件**：订单池达到规划时窗 / 截止时间临近。
1. 计划员（或定时作业）按承运商/截止时间/区域/优先级选择订单 → 创建一个**波次**。
2. 执行分配：先进行软预留，在发布时再进行硬预留；按先进先出（FIFO）/先到期先出（FEFO）/批次定向选择批次（BR-06、BR-07）；检查拣货位并触发补货；通过对数量进行原子预留防止超卖（ADR-0002）。
3. 按拣货方式（单件/批次/分区/集群）生成拣货任务；可选择与上架行程交错。
4. 拣货员扫描库位 + SKU/LP + 数量；系统强制执行控制扫描；短拣 → 填写原因；系统从替代库位/批次重新分配，或转为欠交订单。
5. 已拣 LP 移至打包区。
- **结果**：确认后消耗预留库存；订单行得到满足或标记为短拣；在扫描环节强制保证拣货准确性。

---

## P-05 复核与发运

1. 打包员扫描已拣 LP；系统显示订单、所需数量/批次；逐项复核（强制扫描控制点，BR-08）。
2. 装箱计算推荐纸箱；采集实际重量/体积；按配置执行增值服务（VAS）包装（礼品/插页/标签）。
3. 打印含 SSCC/退货信息的承运商/包裹标签；生成单据。
4. 按月台/拖车暂存；装载员扫描并装入载具；生成装车/发运清单；加封。
5. 发运确认 → 发货过账扣减库存；生成出库预先发货通知（ASN，856）并向客户提供跟踪信息；将发货事件过账至 ERP。
- **异常**：纸箱/订单不匹配时予以阻断；受控货物缺少强制要求的批次/序列号时，阻断发运。
- **结果**：库存已扣减，发货可追溯至客户/订单/批次。

## P-06 循环盘点 → 调整 → 对账

1. ABC 分类计划生成盘点任务（A 类物料盘点最频繁）；此外还会由零库存库位/短拣后条件触发。
2. 盘点员执行**盲盘**（系统隐藏账面数量）；录入实盘数量。
3. 在容差范围内 → 自动调整；超出容差 → 重新盘点/双重盘点。
4. 剩余差异 → 带原因代码的调整申请；主管/库存控制员在规定限额内审批（职责分离（SoD）— CTL-04）。
5. 经批准的调整写入**库存调整事件**（调整前/后、原因、审批人）；过账至 ERP 以进行分类账对账。
- **结果**：恢复准确性并具备完整可审计性；不存在静默覆盖。

## P-07 冻结、隔离与批次召回

- **触发条件**：质检拒收、客户投诉、供应商召回、到期。
- 流程：将批次/序列号或库位库存置为**冻结**状态（阻断分配与出库） → 处置决策（放行/退回供应商/返工/报废） → 执行处置移动/调整 → 对于召回，报告所有入库来源方和出库接收方（EPCIS 追溯）。
- **结果**：受控库存不得发运；召回档案可导出。

## P-08 自动化任务循环（仓储管理系统（WMS）↔ 仓储控制系统（WCS）/仓储执行系统（WES））

1. 仓储管理系统（WMS）创建可由设备执行的任务（托盘移动/将周转箱送至工作站）。
2. 通过**基于任务的接口**向仓储控制系统（WCS）/仓储执行系统（WES）发布任务（ADR-0003）：来源、目的地、LP、优先级；不包含厂商运动原语。
3. 仓储控制系统（WCS）/仓储执行系统（WES）接受并执行任务，发出状态（已接受/已到达/已拣取/已放置/故障），并附带 LP 确认信息。
4. 完成后，仓储管理系统（WMS）应用与人工任务相同的库存变更事件；发生故障 → 异常工作台，可选择回退到人工处理。
- **结果**：无论执行方身份如何，库存变更路径均保持一致。
