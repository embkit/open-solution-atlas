# 03 · 术语表

规范术语；同义词仅为帮助翻译而存在。适用处一律以 ISA-95 词汇优先。

| 术语（英） | 中文 | 定义 |
|---|---|---|
| Production order | 生产订单 | 源自 ERP 的、用于生产一定数量物料的计划（第四级制品，被 MES 引用） |
| Work order | 工单 | MES 可执行的生产订单拆分，绑定一个工艺路线版本 |
| Operation / 工序 | 工序 | 在某个工作中心/工位上执行的一个工艺路线步骤 |
| Routing | 工艺路线 | 带参数的有序工序，带生效日（BR-13） |
| BOM version | 物料清单版本 | 工单下达时所依据的、带生效日的部件清单 |
| Work center | 工作中心 | 可排程的单元（产线、工位组、机台），带有限队列 |
| Station terminal | 工位终端 | 由操作员操作的车间触摸终端 |
| Execution event | 执行事件 | 在源头采集的不可变车间事实（BR-07） |
| Compensating event | 冲正事件 | 引用原事件的仅追加更正（BR-07） |
| Material lot | 物料批次 | 共享历史的某数量物料；谱系节点 |
| Serialized unit | 序列化单件 | 唯一标识的物理单件；最细粒度的谱系节点 |
| Genealogy | 谱系 | 通过工序把批次/单件相连的有向无环图（BR-06） |
| WIP | 在制品 | 已开始但尚未完成的单元/数量 |
| Andon | 安灯 | 异常信号 + 升级工作流（SM-03） |
| Inspection plan | 检验计划 | 按工序的检查项；可以是阻断性的（BR-05） |
| NCR | 不合格处置 | 不合格记录：隔离 → 处置 → 关闭（SM-04） |
| Hold | 冻结 | 在质量决定之前，阻止单元/批次/订单放行的阻断 |
| OEE | 设备综合效率 | 可用率 × 表现 × 质量，公式精确（BR-09） |
| Planned Production Time | 计划生产时间 | 排定时间 − 计划停机（BR-09） |
| Downtime code | 停机原因代码 | DOWN 状态的对齐化原因（BR-08） |
| Backflush | 倒冲 | 从完工数量推导用量的消耗变体模式（FR-010） |
| eDHR / eBR | 电子批次/履历记录 | 受监管变体的电子器械历史/批次记录（FR-016） |
| ISA-95 level 3 | 三级 | 位于 ERP（L4）与控制层（L1–2）之间的执行/运营层 |

## 约定

- 状态名是与状态机中完全一致的大写标记。
- 车间事实不存在「删除」；只有补偿事件。
- 「设备」指制造模型中登记的资产；控制装置只被只读引用（ADR-0003）。
