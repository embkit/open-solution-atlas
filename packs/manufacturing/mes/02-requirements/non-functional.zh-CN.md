# 02 · 非功能需求

场景：以一个工厂为参照单元——≤ 50 条产线 `(A)`、≤ 2,000 台工位终端 `(A)`、
峰值接入 ≤ 5,000 事件/秒 `(A)`、7×24 运行。

> ⚠️ ASSUMPTION (A) — **本文件中的每一个数值目标都是工程预算，而不是测量
> 结果。** 规模档位与全部标注 `(A)` 的取值都是方案包提案，没有外部基准或参考
> 硬件；应按部署重新推导。它们列于
> [`../SOURCES.md` §4](../SOURCES.md)，且**不是**有来源的事实。

| ID | 类别 | 需求（可度量） |
|---|---|---|
| NFR-001 | 延迟 — 实时 | 从采集到产线看板可见 ≤ 2 秒 p95 `(A)`；工位动作确认 ≤ 500 毫秒 p95 `(A)` |
| NFR-002 | 韧性 — 降级模式 | MES 服务不可用时，工位终端在本地缓冲事件 ≥ 4 小时 `(A)` 并在恢复后同步；生产绝不被 MES 停机硬阻断（最后下达的指令离线仍可查看） |
| NFR-003 | 吞吐与规模 | 每厂持续接入 ≥ 5,000 事件/秒 `(A)`；≤ 2,000 台并发终端 `(A)`；5 年事件历史 `(A)` 可在线查询 |
| NFR-004 | 谱系性能 | 完整单元档案（最多 10,000 条关联事件）`(A)` 汇编 ≤ 5 秒 p95 `(A)` |
| NFR-005 | 留存 | 执行事件在线留存 ≥ 5 年 `(A)`；受监管变体：产品寿命 + 2 年 `(A)`，按法规 |
| NFR-006 | 数据完整性 | 仅追加存储（BR-07）；NTP 偏差 ≤ 1 秒 `(A)`（BR-10）；双时间戳（来源 + 接入）；无静默变更——由存储设计强制并被审计 |
| NFR-007 | 可用性 | 生产班次期间 MES 服务 ≥ 99.9 % `(A)`，按月度量；计划内升级不使终端离线（滚动进行、感知班次日历） |
| NFR-008 | 互操作性 | ERP 集成按 ISA-95 对象模型建模（兼容 B2MML 词汇）；设备集成在存在时遵循 OPC UA 配套规范 |
| NFR-009 | 易用性 — 车间 | 例行确认 ≤ 3 次点击 `(A)`；可在 ≥ 10 英寸 `(A)` 触摸终端上戴手套操作；完整本地化含中文；在差的光照下可读（对比度） |
| NFR-010 | 可维护性 | 主数据/检验计划的变更带生效日且无需停机（BR-13）；升级矩阵、原因码、闸门通过配置（而非代码）变更 |
| NFR-011 | 性能 — 分析 | 派工画面刷新 ≤ 1 秒 `(A)`；一个「产线-月」窗口的班次 OEE 报表 ≤ 3 秒 `(A)` |
| NFR-012 | 安全 | 对齐 IEC 62443 的分区；按角色目录的 RBAC；完整的管理审计轨迹；没有直接的 OT 控制写入（CTL-03、ADR-0003） |
| NFR-013 | 可观测性 | 接入延迟、队列深度、集成错误与每班次数据完整性被监控并告警（见 observability.md） |
