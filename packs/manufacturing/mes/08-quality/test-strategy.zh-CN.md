# 08-quality · 测试策略

层级、覆盖目标、测试数据，以及证明 NFR-001..NFR-013 与 CTL-01..CTL-06 的
性能/故障方案。AC 引用见 [`acceptance-criteria.md`](./acceptance-criteria.md)。

## 层级与覆盖目标

| 层级 | 它证明什么 | 特征 | 闸门 |
|---|---|---|---|
| 单元 | 领域不变量：BR-01 数量对账、BR-02 前置顺序、BR-03 单一活动工单、BR-04 备料库存非负、BR-05 闸门强制、BR-09 OEE 公式、BR-13 生效日 | 纯函数，无 I/O | 领域 + OEE + 谱系的行覆盖率 ≥ 90 % |
| 契约 | C-01..C-24 的 OpenAPI 3.1 一致性；RFC 9457 错误形态；幂等请求头；闸门失败列出每个条件 | 按模式校验的请求/响应 | 每个有文档的端点，含伙伴界面 |
| 集成 | ERP 接入→派工→工位动作→消耗→闸门→完成→确认发件箱；WMS 备料回路；LIMS 结果回路 | 临时存储 + 事件日志 + 假 ERP/WMS/LIMS | 顺路径 + 每种故障注入（F-01..F-08） |
| **状态机** | SM-01..SM-05 的迁移，包括非法迁移被拒；下达版本冻结；闸门冻结阻断 DONE | 基于模型 | 覆盖全部 SM 迁移 |
| **仅追加 / 不可变** | 对事件行的篡改尝试被拒；补偿事件绝不修改事实；投影重建是确定性的（C-23） | 日志重放 + 反向测试 | 事实被成功修改的次数为零，否则红灯（BR-07、AC-N04） |
| 并发 | 重复的工位确认（同一幂等键）只追加一次；针对一个备料批次的并发消耗永不超支（BR-04）；闸门竞态（完成 vs. 检验结果）以引擎裁决为准 | 并行测试架 | 无重复事实、无负的备料库存（NFR-006） |
| 性质 | 随机事件序列下的不变量：WIP == fold(events)；Σ 良品+报废+返工 == 完成+报废；从原始事件重算的 OEE == 存储的聚合；谱系图对消耗/产出事件闭合 | 基于性质，带种子 | 每晚 10,000 个随机序列 |
| 降级模式 | 终端缓冲 ≥ 4 小时、离线查看最后下达的指令、恢复后同步无丢失/无重复 | 终端模拟器 + 断路开关 | AC-N02 |
| 端到端 | 经工位终端 / 派工 / 质量工作台模拟器走 BP-01..BP-06 旅程 | 浏览器/终端自动化 | 完整 AC 清单 |
| 性能 | 在参考规模数据集上跑 AC-N01/N03 的接入与延迟画像 | 负载发生器 | 跟踪回归；突破 NFR 即红灯 |
| 安全 / OT 安全 | RBAC 矩阵、kiosk 身份卫生、控制写入探针拒绝、适配器管道白名单、依赖 CVE 扫描 | SAST + 载荷语料 | 任一控制写入路径或角色越界 = 红灯（CTL-03、AC-N06） |
| 控制 | 为一个单元档案做审计重建；完整性清单核验；电子签名仪式反向测试（回填日期、跳过重新认证） | 日志重放 + 反向测试 | 每次运行都生成 CTL-01..CTL-06 的证据 |

## 测试数据

- **主语料：** 50 条产线/工作中心，带设备与协议画像；带批次与序列号跟踪的物料；
  带生效日的 BOM/工艺路线/检验计划版本，含重叠有效期；带技能矩阵与班次日历的
  人员。
- **执行语料：** 植入的动作序列（开始/暂停/恢复/完成、计数）、带时钟偏差的设备
  信号流、重复 `eventId` 重放、来自适配器中断的缺口标记。
- **质量语料：** 阻断性与非阻断性闸门、NOK→NCR→处置链、带失控模式的 SPC 特性
  （Western Electric 风格的植入 `(A)` —— 规则集在方案包的待决问题中被点名）。
- **谱系语料：** 留存窗口之内与之外的单元/批次多层树；被隔离的部件批次；
  10,000 事件的档案单元。
- 不含任何真实工厂、操作员或客户数据；所有标识符都是合成的；依赖时间的测试
  使用可控时钟（班次关闭、升级计时、生效日）。

## 环境与晋级

```
PR        → lint + 单元 + 契约 + SM + 性质（快）
合并       → 集成 + 并发 + 降级模式 + 预发上的安全/OT 安全
发布      → 同一套件 + 性能画像 + 档案完整性演练
每晚      → 10,000 个性质序列 + 投影重建确定性作业
```

## 性能与故障方案

- **AC-N01：** 2,000 台模拟终端 / 5,000 事件/秒形态的接入；断言工位确认与
  看板可见的 p95。
- **AC-N03：** 持续接入 + 10,000 事件档案的汇编计时。
- **故障注入：** 在班次中途杀掉 MES 服务（AC-N02）；丢掉一条设备适配器链路后
  重投（缺口标记，无静默丢失）；损坏/试图改写一个事件行（AC-N04）；让闸门
  完成与检验结果竞态（BR-05 裁决胜出）；ERP 确认发件箱重放（AC-022）。
- **浸泡：** 24 小时峰值接入，观察队列深度、接入延迟、投影漂移与死信队列增长。
