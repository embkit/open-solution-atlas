# 08-quality · 验收标准

每条 AC 都是一条映射到需求 ID 的可证伪测试陈述——也就是本方案包的**完成
定义**。NFR 的 AC（`AC-N*`）以
[`../02-requirements/non-functional.md`](../02-requirements/non-functional.md) 中的
`(A)` 预算为闸门；这些数字是等待被实测值替换的方案包策略。

## 主数据与计划交接

- **AC-001**（FR-001）：修改工艺路线会创建一个带生效日的新版本；一张已下达的
  工单保持其下达时的版本；对任何被引用版本的删除尝试 → `422`。（BR-13）
- **AC-002**（FR-002）：对 CREATED 状态工单的 ERP 变更在授权数量内生效；对
  RELEASED 状态订单的同一变更被拒绝并指明状态；计划量绝不能超过授权量。
  （BR-01）
- **AC-003**（FR-003）：派工按配置的规则（优先级/到期日/换型）排序队列；手工
  重排被持久化并在投影重建后存活。（ADR-0004）
- **AC-004**（FR-004）：在物料未备、工艺路线无效或存在未关闭质量冻结时下达
  → `422` 并列出**每一条**未通过的条件；干净的订单下达时其版本快照被冻结。

## 执行

- **AC-005**（FR-005）：对前道工序未 DONE 的工序发起工位开始 → `422`；一次
  有效序列（开始→计数→完成）为每个动作恰好追加一个事件，并归属到该会话的
  操作员。（BR-02、BR-07）
- **AC-006**（FR-006）：一个来自设备的参数事件被持久化，绑定到工序、单元/批次、
  设备与操作员，且 `source_ts` 与 `ingestion_ts` 相互独立；重放同一 `eventId`
  是空操作。（BR-10）
- **AC-007**（FR-007）：一次 andon 提出按角色与已耗时间通知升级矩阵；确认/解决
  被记录为事件；升级在解决时停止。
- **AC-008**（FR-008）：事件携带会话操作员 id；缺少所需技能的操作员触发配置的
  告警/阻断；kiosk 登出为下一位用户清除身份。（CTL-04）

## 物料与谱系

- **AC-009**（FR-009）：备一个不在已下达 BOM 版本上的批次 → `422` 并给出
  不匹配；正确的扫描可备料且可被消耗。（BR-13）
- **AC-010**（FR-010）：超出备料数量的消耗被拒绝（备料库存不为负）；消耗被
  记录在扫描到的那个批次上，而不是一个平均值上。（BR-04）
- **AC-011**（FR-011）：对一个完工序列号的谱系查询返回在留存窗口内其工序
  消耗的每个部件批次与产出的每个单元；被隔离的部件批次在图中可见。
  （BR-06）
- **AC-012**（FR-012）：在任意动作序列之后，WIP 投影等于 fold(执行事件)；按工序
  的良率汇总匹配 良品/(良品+报废+返工)。

## 质量

- **AC-013**（FR-013）：在没有记录结果的情况下完成带闸门的工序 → 引擎返回
  `422`（经直接 API 绕过界面同样失败）；NOK 结果开立不合格品并把单元路由到
  隔离。（BR-05）
- **AC-014**（FR-014）：SPC 统计按配置规则集在植入的观测上计算；一个失控模式
  告警一次，而不是每个点都告警。
- **AC-015**（FR-015）：开立不合格品会隔离受影响的单元/批次（它们阻断放行与
  发运集成）；带审批的处置写入补偿事件；原事件保持未修改。（BR-07、SM-04）
- **AC-016**（FR-016，变体）：启用 `regulated-edhr` 时，批次记录只从事件汇编；
  一个没有电子签名的配置步骤无法完成；签名绑定确切的记录身份且不得回填日期。
  （BR-11）

## 设备与 OEE

- **AC-017**（FR-017）：一个没有原因码的 DOWN 状态被接受，但在班次关闭时被
  自动编码为 `UNCODED` 并上报给主管；信号来源与人工事件共存而不破坏排序。
  （BR-08）
- **AC-018**（FR-018）：为一个植入的班次计算的 OEE 等于
  `可用率 × 表现 × 质量`（取自植入的已校验事件，其中可用率 = 运行时间 /
  计划生产时间）——从原始事件存储重算返回同一个数字。（BR-09、ISO 22400-2）
- **AC-019**（FR-019，变体）：工装使用计数越过维护阈值时，每次越过恰好触发
  一次告警。

## 可视化与报告

- **AC-020**（FR-020）：在参考负载下，一个工位动作在产线看板投影上于 p95
  预算内出现；看板数据绝不从投影之外的地方读取。（NFR-001）
- **AC-021**（FR-021）：为一个植入单元导出的档案按 BR-06 包含全部事件、检验
  结果与不合格品状态，附带完整性清单，且其哈希在导出后仍可核验。
  （CTL-01、CTL-02）
- **AC-022**（FR-002/ADR-0001）：ERP 确认发件箱每次完成恰好发出一条确认，含
  erp 订单 id + MES 幂等键；发件箱重放不产生重复确认。

## NFR / 性能闸门（预算 `(A)`）

- **AC-N01**（NFR-001）：在参考的 2,000 终端 / 5,000 事件/秒形态负载下，工位
  动作确认 p95 ≤ 500 毫秒且看板可见 p95 ≤ 2 秒；断言实测 p95。
- **AC-N02**（NFR-002）：在班次中途杀掉 MES 服务；终端在本地缓冲 ≥ 4 小时的
  事件，保持最后下达的指令可见，并在恢复后无丢失、无重复地同步（幂等重放）。
- **AC-N03**（NFR-003/004）：5,000 事件/秒的持续接入稳住；一份 10,000 事件的
  档案汇编 ≤ 5 秒 p95。
- **AC-N04**（NFR-006）：对一个已存事件的篡改尝试被拒绝；由事件存储重建的
  投影复现出完全相同的投影（确定性）；双时间戳端到端保留。
- **AC-N05**（NFR-007）：滚动升级保持 ≥ 99.9 % 的月度可用性；升级期间没有
  终端离线窗口（感知班次日历）。
- **AC-N06**（NFR-012/CTL-03）：没有任何契约或适配器路径写入控制回路；一次
  试图写控制参数的探针被拒绝并被审计；RBAC 矩阵拒绝跨角色访问。
