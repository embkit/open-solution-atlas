# 01 · 业务规则

> 规则的 ID 是稳定的。理由中提及标准的规则会追溯到该标准
> （例如 BR-09 → ISO 22400-2:2014；BR-06 → ISO 9001:2015 8.5.2）。这些规则中
> 其余的数值参数（BR-08 自动编码时机、BR-10 `偏差 ≤ 1 秒`、BR-13 生效日
> 行为）是**方案包策略**，不是有来源的事实——见
> [`../SOURCES.md` §4](../SOURCES.md)。

| ID | 规则 | 理由 |
|---|---|---|
| BR-01 | 工单数量的变更与 ERP 生产订单对账；未经 ERP 侧变更，MES 不得超出授权订单数量 | 单一规划权威（ADR-0001） |
| BR-02 | 一道工序在其工艺路线前道未完成、物料未备齐时不能开始 | 执行完整性 |
| BR-03 | 一个在制品单元（序列化单元或批次拆分）在任一时刻恰好属于一个活动工单 | 无歧义的谱系 |
| BR-04 | 车间物料批次库存永不为负；超出备料数量的消耗被拒绝 | 物理真相 |
| BR-05 | 阻断性检验闸门由工作流引擎强制——无论界面如何，没有记录结果的完成都被拒绝 | 质量保证（CTL-01） |
| BR-06 | 谱系完整性：每个完工单元都可追溯到所有关键部件的批次、工艺参数、设备以及接触过它的人员 | ISO 9001 8.5.2；审计 |
| BR-07 | 执行事件仅可追加；更正以引用原事件的补偿事件表达；没有任何东西被编辑或删除 | ADR-0002；数据完整性（CTL-02） |
| BR-08 | 停机在班次关闭前必须带原因码；未编码的停机被自动编码为 `UNCODED` 并上报给主管 | OEE 可信度 |
| BR-09 | OEE 只从已校验的状态事件计算，公式精确：OEE = 可用率 × 表现 × 质量；可用率 = 运行时间 / 计划生产时间；表现 =（理想节拍 × 总数）/ 运行时间；质量 = 良品数 / 总数；计划生产时间 = 排定时间 − 计划停机。任何偏差都必须是显式标注的变体指标 | **ISO 22400-2:2014**（OEE 指数 = 可用率 × 效率 × 质量之比）；损失时机的边缘情形（计划停机、理想节拍）是方案包的选择 |
| BR-10 | 车间时钟经 NTP 同步，偏差 ≤ 1 秒；事件同时携带来源时间戳与接入时间戳 | 事件排序（NFR-006） |
| BR-11 | 仅受监管变体：需要电子签名的记录步骤不得回填日期；签名绑定确切的事件身份 | 21 CFR Part 11 / 附件 11 |
| BR-12 | MES 对设备的写入限于非控制类外设（标签打印机、andon 显示屏）；MES 绝不写入控制回路参数 | 安全（ADR-0003、CTL-03） |
| BR-13 | 主数据（工艺路线、BOM、检验计划）的变更带生效日；在制工单保持其下达时的版本 | 可复现性 |
