# 01 · 核心业务流程

> ⚠️ ASSUMPTION — BP-01..BP-06 的流程流属于方案包设计（一次通用的 ISA-95
> 第三级活动分解），而不是 IEC 62264-3 的规范文本（见
> [`../SOURCES.md` §4](../SOURCES.md)）。

## BP-01 端到端执行一张生产订单

```
ERP 生产订单 ──接入──▶ 按工艺路线派生工单 (FR-002)
   │                                │ 派工到工作中心 (FR-003)
   │                                ▼
   │                     下达闸门 (FR-004)：物料已备 +
   │                     工艺路线有效 + 无质量冻结
   │                                ▼
   │                     工位执行 (FR-005/006)：开始 → 运行 →
   │                     完成；计数与参数记录为事件 (BR-07)
   │                                ▼
   │                     计划中的质量闸门 (BP-03)
   │                                ▼
   ▼                                ▼
完成并确认回传 ERP ◀── OEE/良率更新 (FR-018)
```

数量与 ERP 订单对账（BR-01）；工序遵循工艺路线顺序（BR-02）。

## BP-02 备料与消耗物料

每张工单的备料清单 → 扫码核验（FR-009）→ 每道工序按批次消耗（FR-010）→ 写入
谱系边（FR-011）→ 更新在制品（FR-012）。批次库存不为负（BR-04）；每个单元恰好
关联一个活动订单（BR-03）。

## BP-03 过程内质量闸门

工序完成 → 触发检验计划（FR-013）→ 结果合格 → 下一道工序解锁；结果不合格 →
开立不合格品，单元隔离（FR-015）→ 处置（返工 / 报废 / 让步接收）→ 记录放行或
报废。阻断性闸门不可跳过（BR-05）。

## BP-04 异常与 andon

操作员或设备提出异常（FR-007）→ 确认 → 按矩阵升级（时间/角色）→ 解决方案 +
停机编码（FR-017）→ 馈入 OEE 与班次报表。

## BP-05 可追溯性档案

按序列号 / 批次 / 订单 / 日期查询（FR-021）→ 反向遍历（哪些批次与部件进入了
这个单元）与正向遍历（这个批次被用在了哪里）→ 汇总档案：工艺参数、设备、人员、
检验 → 导出以备审计或客户投诉。

## BP-06 班次关闭与数据质量

班次结束 → 停机码补齐或取默认值（BR-08）→ 完整性检查（标记缺失的读数）→
发布该班次的 OEE → 向下一班与管理层交接摘要。
