# 00 · 干系人

| 参与者 | 身份 | 目标 | 约束 / 顾虑 |
|---|---|---|---|
| 厂长 | 对产出、成本、质量负责 | 可信的实时可见性；更少意外 | KPI 必须反映数据质量（BR-09），而不是猜测 |
| 生产计划员（ERP 侧） | 第四级规划 | 事实快速回流以便重新规划 | MES 绝不能复制规划权威 |
| 线长 / 调度员 | 班次级编排 | 快速派工、异常处理、交接 | 实时看板；压力下尽量少的点击 |
| 操作员 | 执行操作 | 明确的指令、快速的确认 | 戴手套/触控界面、本地语言、例行操作 ≤ 3 次点击 |
| 质量工程师 | 检验计划、不合格品处置 | 不可跳过的闸门；可信的档案 | 闸门由技术强制（BR-05），而不是靠约定 |
| 维修技术员 | 设备与停机 | 准确的编码、预防性维护触发 | 维修期间在产线侧/移动端录入 |
| OT/自动化工程师 | PLC/SCADA/网关 | 干净的接口、零控制干扰 | IEC 62443 区域；只能在变更窗口内操作 |
| 厂区 IT | 平台运维 | 安全升级、备份、安全 | 7×24 约束；滚动升级 |
| 审计员 / 客户 | 可追溯性证据 | 几分钟内拿出完整档案 | 仅追加的记录；受监管变体中的签名 |
| 监管机构（受监管变体） | 合规监督 | 有效的电子记录/电子签名 | 21 CFR Part 11；EU GMP 附件 11 |

## 信任边界（摘要；细节见 04-architecture/security.md）

- **OT 区域**（PLC/SCADA）：MES 是读取数据的客户端——绝不是一个写入控制的权威
  （ADR-0003）。
- **MES 区域**：事件存储 + 服务——车间事实的唯一写入方。
- **IT 区域 / DMZ**：ERP 与云同步只经受控的管道。
- **工位终端**：共享设备；身份通过工牌/登录确定；按 kiosk 方式加固；所有动作
  可归属（CTL-04）。
