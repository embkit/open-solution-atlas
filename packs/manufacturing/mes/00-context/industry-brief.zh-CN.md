# 00 · 行业简报 — 制造执行

## 这套系统服务的业务

制造商必须把 ERP 的生产计划变成被执行、被记录、可追溯的车间作业。MES 是
ISA-95/IEC 62264 层次中的**第三级**系统：它从 ERP（第四级）接收计划订单，
在产线与工位上编排其执行（第三级），并从自动化层（第一至二级）读取状态与
参数——而它自身既不控制机器，也不重新规划供应链。

价值主张同时是监管性的与经济性的：

- **可追溯性**：证明造出了什么、用了哪些物料批次、由谁、在哪台设备上、用
  哪些参数造出的——ISO 9001 的客户、审计员与监管机构（医疗器械、 pharma、
  汽车、食品）都要求这一点。
- **良率与 OEE**：精确暴露时间与物料损失在哪里发生。
- **无纸化执行**：取代那些既答不了审计、也答不了客户投诉的班次纸单。

## 价值链

```
ERP plan (L4) ──▶ MES dispatch (L3) ──▶ station execution ──▶ event capture
                                                              │
        reporting & audit ◀── OEE / quality / genealogy ◀─────┘
```

## 塑造设计的市场现实

1. **异构且老旧的设备存量。** 产线上混着现代 OPC UA PLC、1990 年代的串口
   设备，以及纯人工工位。一个假定协议统一的 MES 会失败；协议适配器与边缘
   网关是结构性的，而不是可选的（ADR-0003）。
2. **OT/IT 分离是强制要求。** 工厂网络按 IEC 62443 分段；办公 IT 的模式不能
   直接套到车间。
3. **使用者不是办公室职员。** 戴手套的操作员、十秒级的交互、班次交接、噪音、
   差的光照。终端体验是硬性要求，不是一个样式问题。
4. **7×24 运行，对停产零容忍。** MES 必须以降级方式失败（工位侧缓冲），绝不
   阻断产线，并支持围绕班次日历的滚动升级。
5. **行业差异是实质性的。** 离散装配（序列化单元、工位平衡）、流程/批次
   （批次、配方、阶段）与受监管变体（带电子签名的 eDHR/eBR）差异足够大，因此
   一个带显式变体的内核胜过一个假装能容纳一切的巨型系统。
6. **ERP 拥有规划的真相。** 重复的规划数据会漂移并导致过量生产；MES 消费
   计划并回报事实。

## 典型部署场景

| 场景 | 说明 |
|---|---|
| 厂区本地部署（边缘/虚机服务器） | 默认；满足 OT 分段与延迟要求 |
| 集团数据中心 + 厂区边缘 | 分析集中，执行面留在厂区 |
| 云混合 | 历史/分析在云中；执行绝不依赖 WAN |
| 信创 / 国产技术栈（中国） | 变体覆盖层；内核保持可移植 |

## 来源

- ISA-95 / IEC 62264 —— 企业与控制系统集成
- IEC 62443 —— 工业自动化与控制系统安全
- ISO 9001:2015 第 8.5.2 条 —— 标识与可追溯性
- FDA 21 CFR Part 11；EU GMP 附件 11 —— 受监管变体的电子记录
