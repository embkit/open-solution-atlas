# 09-delivery · 里程碑

按依赖排序的构建计划。每个里程碑都可演示，且只有通过其验证闸门才退出。任务
ID（`T-xx`）见 [`task-map.md`](./task-map.md)；AC ID 见
[`../08-quality/acceptance-criteria.md`](../08-quality/acceptance-criteria.md)。

| 里程碑 | 范围 | 退出闸门 |
|---|---|---|
| **M0 — 事件主干与身份** | 仅追加的执行事件存储、补偿式更正、投影框架 + 重建（C-23）、双时间戳、RBAC/kiosk 会话 | AC-N04、AC-008；投影重建的确定性 |
| **M1 — 主数据与 ERP 交接** | 带生效日的主数据模型（C-01/02）、带版本引用的 ERP 接入/取消（C-03）、确认发件箱（C-05） | AC-001、AC-002、AC-022 |
| **M2 — 派工与下达** | 派工队列 + 手工重排、下达闸门（C-04） | AC-003、AC-004 |
| **M3 — 执行与工位** | 操作员会话、工位动作、人工 + 设备事件接入、andon（C-06..C-09）、终端缓冲 | AC-005..AC-007、AC-N02 |
| **M4 — 物料与谱系** | 扫码核验的备料、批次消耗、谱系遍历、WIP 投影（C-10..C-13） | AC-009..AC-012 |
| **M5 — 质量执行** | 阻断性闸门、SPC 基线、不合格品/隔离/处置（C-14..C-16）；`regulated-edhr` 变体钩子（C-17） | AC-013..AC-016 |
| **M6 — 设备与 OEE** | 带自动编码的状态/停机采集、公式精确的 OEE（C-18/19）、工装计数（C-20） | AC-017、AC-018、AC-019 |
| **M7 — 可视化、档案与加固** | 产线看板/派工画面（C-21）、可追溯性档案 + 完整性清单（C-22）、WMS/LIMS 回路（C-24）、性能与 OT 安全方案 | AC-020、AC-021、AC-N01、AC-N03、AC-N05、AC-N06 |

## 排序说明

- M6（设备/OEE）只依赖 M0（事件）与 M1（设备主数据）；M0 落地后它可以与
  M3–M5 并行。
- 闸门（BR-05）必须在 M3 的完成动作变得有意义之前就存在——在 M3 先建闸门
  *桩*，在 M5 完整强制它；引擎侧的拒绝（AC-013）是 M5 的退出条件。
- 性能闸门（AC-N01/N03）在 M7 用参考规模的数据集运行；降级模式（AC-N02）是
  M3 的退出条件，因为终端自主性是一项底线要求，而不是事后加固。
