# 09-delivery · 智能体可执行的任务地图

每个任务的规模都对应一次专注的智能体改动，并带一个验证钩子。ID 为 `T-xx`；
每个都映射到一个里程碑以及 FR/BR/NFR/CTL/AC 的 ID。按里程碑顺序执行；
**不要跳过验证钩子**。

## M0 — 事件主干与身份

- **T-01** 仅追加的执行事件存储：有序、不可变、哈希链、先持久写入再回执、
  `source_ts`+`ingestion_ts`（BR-07、BR-10）。验证：篡改尝试被拒；重放是
  确定性的。[AC-N04]
- **T-02** 补偿事件机制：更正引用原事件，原事件不受影响。验证：更正改变的是
  投影，而不是历史。[BR-07、AC-015]
- **T-03** 投影框架 + 重建（C-23）：在制品/良率的折叠，带持续对账。验证：在
  植入的序列上 重建 == 实时投影；分叉会呼叫值班。[ADR-0002、AC-N04、AC-012]
- **T-04** IAM：RBAC 角色（操作员/质量/调度员/主数据/审计）、按 kiosk 方式
  加固的会话、管理动作审计。验证：跨角色探针被拒；登出清除身份。
  [FR-008、CTL-04、AC-008]

## M1 — 主数据与 ERP 交接

- **T-05** 带生效日的主数据模型：工厂/产线/工作中心/设备/物料 + BOM/工艺路线/
  检验版本（C-01/02）。验证：被引用版本的删除 → 422；重叠消解。
  [FR-001、BR-13、AC-001]
- **T-06** ERP 生产订单接入：创建/变更/取消、数量对账、仅 CREATED 可变更
  （C-03）。验证：对 RELEASED 的变更被拒；超授权被拒。
  [FR-002、BR-01、AC-002]
- **T-07** 带订单 id + MES 幂等键的 ERP 确认发件箱（C-05）。验证：重放恰好
  产生一条确认。[AC-022]
- **T-08** 人员/班次日历 + 技能矩阵（C-01）。验证：技能不匹配按配置触发
  告警/阻断。[FR-008]

## M2 — 派工与下达

- **T-09** 派工队列：可配置规则（优先级/到期/换型）+ 手工重排的持久化
  （C-04）。验证：重排在投影重建后存活。[FR-003、ADR-0004、AC-003]
- **T-10** 下达闸门：已备物料 + 工艺路线有效性 + 冻结检查，通过时冻结版本
  （C-04）。验证：失败列出每个条件；已下达快照被冻结。
  [FR-004、BR-02、BR-13、AC-004]

## M3 — 执行与工位

- **T-11** 带就绪校验的工位动作端点（C-06）：开始/暂停/恢复/完成 + 计数。
  验证：前道未 DONE → 422；每个动作一个事件。[FR-005、BR-02、AC-005]
- **T-12** 人工事件采集 + 设备接入面（C-07），带幂等 `eventId`。验证：重放是
  空操作；绑定齐备。[FR-006、BR-10、AC-006]
- **T-13** Andon 生命周期 + 升级矩阵（C-08）。验证：按角色定时升级；解决后
  停止通知。[FR-007、AC-007]
- **T-14** 终端降级模式：本地缓冲 ≥ 4 小时、离线查看最后下达的指令、恢复后
  同步。验证：断服务演练不丢、不重。[NFR-002、AC-N02]

## M4 — 物料与谱系

- **T-15** 对照已下达 BOM 版本的扫码核验备料（C-10）。验证：错批次扫描 →
  422 并给出不匹配细节。[FR-009、BR-13、AC-009]
- **T-16** 带备料库存守卫的批次级消耗（C-11）。验证：并发消耗永不超支备料
  数量。[FR-010、BR-04、AC-010]
- **T-17** 谱系遍历（C-12），含被隔离批次的可见性。验证：在植入的树上完整
  正向/反向闭合。[FR-011、BR-06、AC-011]
- **T-18** WIP 投影 + 良率汇总（C-13）。验证：随机序列后 WIP == fold(events)。
  [FR-012、BR-03、AC-012]

## M5 — 质量执行

- **T-19** 工作流引擎中的检验闸门强制（C-14）：无结果的完成在 API 层被拒。
  验证：界面与直接 API 的绕过都失败；NOK 开立不合格品。
  [FR-013、BR-05、AC-013]
- **T-20** SPC 基线：可配置规则集、控制图统计、每个模式一次告警（C-15）。
  验证：植入的失控模式告警一次。[FR-014、AC-014]
- **T-21** 不合格品 + 隔离 + 带职责分离审批的处置 + 补偿事件（C-16）。验证：
  被隔离的单元阻断放行/发运；原事件未修改。[FR-015、BR-07、SM-04、AC-015]
- **T-22** `regulated-edhr` 变体钩子：由事件汇编的记录 + 电子签名仪式
  （C-17）。验证：未签名的步骤无法完成；回填日期被拒。
  [FR-016、BR-11、AC-016]

## M6 — 设备与 OEE

- **T-23** 带原因码的设备状态/停机接入（信号 + 人工）（C-18）。验证：交错的
  来源保持按设备的顺序。[FR-017、AC-017]
- **T-24** 未编码停机的自动编码 + 班次关闭时的主管报表。验证：仅为未关闭的
  停机填充 UNCODED。[BR-08、AC-017]
- **T-25** 严格按 BR-09 在所有范围/班次上计算 OEE（C-19）。验证：植入的班次
  复现公式数值；从事件重算完全一致。[FR-018、BR-09、AC-018]
- **T-26** 工装使用计数 + 阈值告警（C-20，变体）。验证：每次越过恰好一次
  告警。[FR-019、AC-019]

## M7 — 可视化、档案与加固

- **T-27** 只从投影读取的产线看板 + 派工画面（C-21）。验证：看板读取绝不
  触及源表；负载下 p95 在预算内。[FR-020、NFR-001、NFR-011、AC-020]
- **T-28** 带完整性清单的可追溯性档案导出（C-22）。验证：植入单元上的完整性；
  导出后哈希可核验。[FR-021、CTL-01/02、AC-021]
- **T-29** WMS 备料回路 + LIMS 结果回路（C-24），中断时带缺口标记。验证：
  中断发出缺口；班次关闭完整性标记未对账的窗口。
  [集成 I-03/I-04、AC-N04]
- **T-30** 性能与 OT 安全方案：接入/确认/看板 p95、档案计时、控制写入探针
  拒绝、滚动升级演练。验证：AC-N01/N03/N05/N06。
  [NFR-001/003/004/007/012、CTL-03]
