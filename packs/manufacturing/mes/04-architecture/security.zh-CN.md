# 04 · 安全

## 区域与管道（对齐 IEC 62443）

```
[OT 区域]          [MES 区域]                 [DMZ]            [IT 区域]
PLC/SCADA  ─管道→  适配器 → 事件接入 ─管道→  网关  ─管道→  ERP/WMS/LIMS/云
   （以读为主；      （车间事实的唯一写入方）           （业务系统；
   MES 绝不写                            每条管道用最小权限
   控制 —— BR-12）                        服务账号）
```

- 终端位于车间分段；它们用设备证书 + 操作员登录向 MES 认证；无直接 OT 可达性。
- 每条管道都穿越带显式白名单的防火墙；没有扁平网络（CTL-03）。

## 身份与访问

- 角色目录：操作员、主管、调度员、质量、维修、OT 工程师、IT 管理员——按角色
  最小权限；质量处置与生产角色之间分离。
- 共享终端上的操作员归属（FR-008）：每个班次会话用工牌/登录；空闲重新上锁
  ≤ 5 分钟；所有管理变更被审计（CTL-04）。
- 受监管变体：电子签名仪式 = 重新认证 + 绑定到确切事件身份的签名含义
  （BR-11、CTL-02）。

## 终端与平台加固

- Kiosk 模式：无操作系统 shell、已签名的应用、自动恢复、本地事件缓冲静态
  加密（NFR-002）。
- 厂区服务器：最小化基础镜像，在生产变更窗口内打补丁，备份由恢复演练检验；
  事件存储复制。
- 机密绝不在终端镜像中；每设备证书轮换。

## 威胁说明（节选）

| 威胁 | 缓解 |
|---|---|
| 经 MES 的 OT 入侵 | 只读 OT 管道；无控制写入（BR-12）；适配器进程隔离 |
| 事件篡改 | 仅追加存储 + 序列完整性（BR-07）；管理审计（CTL-04） |
| 终端被盗 | 吊销设备证书；操作员重新认证；加密的本地缓冲 |
| 内部人员误批（质量） | 角色分离；不合格品审批按身份记录（FR-015） |
| ERP 伪造订单 | DMZ 网关上的双向认证；版本对账检查（I-01） |
