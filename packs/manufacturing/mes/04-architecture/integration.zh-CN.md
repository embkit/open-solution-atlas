# 04 · 集成

> L3 数据流规范。协议/报文名称在 [`../SOURCES.md`](../SOURCES.md) 中引用；
> 频率、载荷形态与重试策略是方案包默认值 `(A)`——由部署画像替换。

## 集成清单

| # | 对手方 | 协议 / 词汇 | 方向 | 数据 | 节奏 |
|---|---|---|---|---|---|
| I-01 | ERP | 消息队列或 API 上的 B2MML/ISA-95 词汇 | 双向 | 生产订单、BOM/工艺路线版本 →；工单确认、数量 ← | 事件 + 周期性对账 |
| I-02 | SCADA / 边缘网关 | OPC UA（首选）、MQTT、经适配器的文件/串口 | 入（以读为主） | 设备状态、计数、工艺参数 | 流式 |
| I-03 | WMS | API 事件 | 双向 | 备料请求 →；已备/已拣确认 ← | 事件 |
| I-04 | LIMS / QMS | API | 双向 | 检验规范 →；实验室结果 ← | 事件 |
| I-05 | 集团 DWH / 云 | 复制的事件或聚合 | 出 | OEE、良率、可追溯性抽取 | 批量/流式 |
| I-06 | 标签打印机 / andon 显示屏 | 厂商 API / 网络打印 | 出（仅非控制） | 标签、看板内容 | 事件 |

## 契约规则

1. **带生效日的交接（BR-13）**：ERP 发送 BOM/工艺路线版本标识；MES 绝不从
   ERP 的实时状态重新推导主数据。
2. **幂等的确认**：给 ERP 的每条确认都携带 ERP 订单 id + 一个 MES 幂等键；
   重放是安全的。
3. **对 OT 以读为主（BR-12/ADR-0003）**：MES 订阅设备数据；写命令只允许发往
   非控制类外设（I-06）。
4. **缺口处理**：集成中断绝不能静默丢弃事实——适配器发出缺口标记；班次关闭
   完整性检查（BP-06）暴露未对账的窗口。
5. **以事件重放作为恢复**：集成通过重放事件存储重建状态；没有任何集成拥有
   真相（ADR-0002）。

## 设备适配器模式（ADR-0003 摘要）

```
PLC/SCADA ──OPC UA/MQTT──▶ 适配器 (DMZ) ──规范化事件──▶ 接入
                 ▲                        │
        标签/配套规范映射     只允许写入：打印机、andon 显示屏
```

适配器把工厂专有标签映射到规范事件模型；新增一条产线 = 新增一个适配器画像，
内核不变（NFR-010）。

## 数据流细节（L3）

> 频率是 `(A)` 默认值；每条流都是至少一次投递，且消费方按所述键幂等。所有
> 时间戳为 ISO-8601 UTC，并做来源/接入双记录（BR-10）。

### F-01 ERP 订单交接（ERP ⇄ MES）

| 方面 | 规范 |
|---|---|
| 传输 | 带 B2MML/ISA-95 词汇的消息队列或 API（I-01、C-03/C-05） |
| 载荷要点 | 入站：生产订单 + 物料 + 授权数量 + BOM/工艺路线**版本标识**（绝不含实时主数据）；出站：带 erp 订单 id + MES 幂等键的确认 |
| 频率 | 订单事件时；出站确认在完成/取消时；夜间对账 `(A)` |
| 幂等性 | ERP 命令 id（入站）；订单 id + MES 键（出站） |
| 失败 | 未知版本 → 422，不产生部分工单；发件箱重试且不重复；对非 CREATED 状态订单的变更被拒绝并指明状态（AC-002） |

### F-02 设备接入（PLC/SCADA → 适配器 → MES）

| 方面 | 规范 |
|---|---|
| 传输 | OPC UA 订阅（首选）、MQTT、经 DMZ 适配器的文件/串口（I-02、C-07/C-18） |
| 载荷要点 | 规范化的状态/停机事件、计数、工艺参数，绑定到设备 + 工序 + 单元/批次引用 |
| 频率 | 状态变化时；参数按标签画像采样 `(A)` |
| 幂等性 | 适配器提供的 `eventId`，由标签 + 来源时间戳派生 |
| 失败 | 适配器中断发出缺口标记；班次关闭完整性标记未对账的窗口——事实绝不被静默丢弃；重放重建状态（集成规则 5） |

### F-03 WMS 备料回路（MES ⇄ WMS）

| 方面 | 规范 |
|---|---|
| 传输 | HTTPS JSON 事件，mTLS（I-03、C-24） |
| 载荷要点 | 备料请求（物料、批次、数量，对照已下达的 BOM 版本）→；已备/已拣确认 ← |
| 频率 | 备料请求/确认时 `(A)` |
| 幂等性 | `(workOrderId, stagingSeq)` |
| 失败 | 请求与确认之间的不匹配会开启一个带类型的差异；超出已确认备料库存的消耗被拒绝（BR-04） |

### F-04 LIMS 边界（MES ⇄ LIMS）

| 方面 | 规范 |
|---|---|
| 传输 | HTTPS JSON，mTLS（I-04、C-24） |
| 载荷要点 | 出站检验规范/计划引用；入站实验室结果，绑定到检验 id 与闸门 |
| 频率 | 每次检验派发/出结果 `(A)` |
| 幂等性 | 检验 id |
| 失败 | 班次关闭后到达的实验室结果作为迟到事实记录并带两个时间戳；闸门保持关闭，直到有结果或明确的处置（BR-05） |

### F-05 分析导出（MES → DWH/云）

| 方面 | 规范 |
|---|---|
| 传输 | 复制的事件流或聚合批次（I-05） |
| 载荷要点 | 执行事件 / OEE 与良率聚合；除操作员引用外不含个人数据 `(A)` |
| 频率 | 流式或每日批次 `(A)` |
| 幂等性 | 事件 id / 聚合周期键 |
| 失败 | 下游延迟绝不对车间接入形成反压；导出是只读的（ADR-0002） |

### F-06 外设写入（MES → 打印机 / andon 显示屏）

| 方面 | 规范 |
|---|---|
| 传输 | 厂商 API / 网络打印（I-06，唯一被允许的 OT 方向写入，BR-12） |
| 载荷要点 | 标签内容、看板显示数据——绝不是控制参数 |
| 频率 | 打印请求时 / 看板刷新在 NFR-001 预算内 |
| 幂等性 | 请求 id；重复打印是一次可见的、被审计的重复 |
| 失败 | 外设故障引发一个 andon 型异常；绝不让重试风暴涌入 OT 网络 |

## 协议版本锁定（待办项，见第 4 节）

B2MML 版本与按设备的 OPC UA 配套规范清单是记录在适配器画像中的部署输入，
而非硬编码；「兼容 B2MML 的词汇」指 ISA-95 对象模型的形态（IEC 62264-2/-4），
按部署锁定。
