# 04 · 可观测性

工厂 7×24 运行、IT 团队却很小：监控必须像发现基础设施问题一样大声地发现
**数据质量**问题（MES 的第一大失败模式）。

## 信号

| 层 | 信号 | 阈值 / 动作 |
|---|---|---|
| 接入 | 事件/秒、校验拒绝数、按来源的序列缺口 | 缺口或拒绝激增 → 告警 OT/值班；来源被隔离 |
| 终端集群 | 在线终端数 vs. 预期名册；本地缓冲增长 | > 5 % 的工位缓冲 > 0 → 降级模式告警 |
| 集成 | ERP/WMS/LIMS 队列深度、对账差值 | 班次关闭时仍有未解决差值 → 阻断该班次 OEE 发布标志 |
| 数据完整性（BP-06） | 无计数的工序、未编码的停机、对照计划的缺失参数 | 班次关闭时仍不完整 → 主管摘要 + BR-08 自动编码报告 |
| OEE 可信度（BR-09） | 已校验事件占比、时钟偏差事件 | 偏差 > 1 秒 → NTP 整改告警 |
| 谱系 | 档案构建失败、孤立边 | 任一孤立边 → 数据完整性事件 |
| 平台 | 服务健康、复制延迟、备机接管 | 复制延迟 > 30 秒 → 告警；故障切换 → 呼叫值班 |

## SLO（面向工厂）

- 看板新鲜度 ≤ 2 秒 p95（NFR-001）；班内接入可用性 99.9 %（NFR-007）；档案
  ≤ 5 秒 p95（NFR-004）。
- 班次关闭完整性 ≥ 预期事件的 99 % 已采集——与 OEE 一并按班次发布，让 KPI
  消费方看到数据可信度。

## 运维节奏

- 每班次：向主管自动推送完整性摘要（BP-06）。
- 每日：ERP ↔ MES 对账报表（数量，BR-01）。
- 每周：适配器健康复核（滞后来源、缺口标记）。
- 每季度：把事件存储恢复到预发工厂画像的演练。
