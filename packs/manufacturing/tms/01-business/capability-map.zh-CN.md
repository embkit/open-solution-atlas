# 01 · 能力地图

> L1 地图，为 L2 做了细化。CAP 的 ID 是稳定的。

| CAP | 能力 | 包含 |
|---|---|---|
| **CAP-01** | 运输订单管理 | CAP-01.1 需求接入（ERP/WMS）、CAP-01.2 集拼、CAP-01.3 多段运输 |
| **CAP-02** | 承运商与费率管理 | CAP-02.1 承运商主数据与资质、CAP-02.2 费率卡/合同（带生效日期）、CAP-02.3 即时询价 |
| **CAP-03** | 装载规划 | CAP-03.1 装载构建（方/重）、CAP-03.2 运力校验、CAP-03.3 车辆/资源选择 |
| **CAP-04** | 路径与派车 | CAP-04.1 路径规划与停靠排序、CAP-04.2 招标/接单、CAP-04.3 司机/车辆分配 |
| **CAP-05** | 在途可视化 | CAP-05.1 里程碑事件采集（车载终端/EDI/手工）、CAP-05.2 ETA 与异常管理、CAP-05.3 送达证明 |
| **CAP-06** | 运费结算 | CAP-06.1 依据费率快照计算成本、CAP-06.2 发票审计与三向匹配、CAP-06.3 承运商结算与争议 |
| **CAP-07** | 危险品合规 | CAP-07.1 分类元数据、CAP-07.2 隔离/装载校验、CAP-07.3 单证支持 |
| **CAP-08** | 集成 | CAP-08.1 ERP/WMS 交接、CAP-08.2 承运商 EDI/API（EDIFACT/X12/REST）、CAP-08.3 EPCIS 事件发布 |

## 边界（这张地图刻意排除什么）

- 仓库执行内部细节 → 兄弟方案包 `wms`（只做交接）
- 海关/贸易合规引擎 → 候选兄弟方案包
- 车载终端设备管理 → 外部集成来源
- 车队维护与司机工时的法定强制执行 → 只消费属性，不强制执行
