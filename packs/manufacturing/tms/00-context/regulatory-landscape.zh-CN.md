# 00 · 法规环境

> 版本核验于 2026-10-08。完整可追溯性见
> [`../SOURCES.md`](../SOURCES.md)。

## 核心（始终适用）

| 领域 | 依据文件 | 版本 / 状态 | 与 TMS 的关系 |
|---|---|---|---|
| 运输事件词汇 | **GS1 EPCIS 2.0 / CBV 2.0** | 2022-06 批准 | track-and-trace 事件共享的里程碑/处置词汇；自 2.0 起支持 JSON/JSON-LD + REST 捕获/查询 |
| 供应链安全 | **ISO 28000:2022**（第 2 版） | 2022-03 发布 | 供应链安全管理体系；CTL-03 的框架 |
| 贸易术语 | **Incoterms® 2020**（ICC） | 2020-01-01 生效；11 条规则 | 在卖方与买方之间分配成本/风险/义务；决定*谁与谁订立运输合同*——TMS 只消费，绝不重新定义该术语 |
| 货运报文交换 | **UN/EDIFACT** IFTMIN/IFTMBF（指令）、IFTSTA/IFCSUM（状态） | 报文名称固定；版本按协议对确定 | 用于订单与状态交换的传统/外包 EDI 通道 |
| 北美状态报文 | **ANSI ASC X12** 214（运输状态）、990（响应） | 交易集；版本按交易伙伴确定 | 美国贸易中的承运商状态 EDI |

## 危险品（与变体相关；是校验数据，不是法律文本）

| 方式 | 依据文件 | 核验版本 | 说明 |
|---|---|---|---|
| 公路（国际，UNECE） | **ADR 2025** | 修正案自 2025-01-01 起适用（UN 文号 ECE/TRANS/352） | 两年一循环：下一版 ADR 为 2027 |
| 公路（中国） | **JT/T 617-2018**（7 个部分）+ **GB 6944-2025** | JT/T 617 第 1–7 部分于 2018-08-29 发布；GB 6944-2025 自 2025-10-01 生效（替代 2012 版） | 中国的分类/托运/装载/车辆规则 |
| 海运 | **IMDG Code 2024 版**（含 42-24 修正案） | 自 2026-01-01 起强制适用（2024-05 通过 MSC.556(108)） | 自 2025-01-01 起允许自愿适用 |
| 空运 | **IATA DGR 第 67 版（2026）** | 2026-01-01 生效 | 每年一版；第 68 版（2027）已发布 |

> 本方案包针对这些表编码**合规元数据校验**（UN 编号、正式运输名称、类别/
  项别、包装类别、数量限制、隔离要求）。它绝不把法规文本当作系统逻辑复制
  ——见 ADR-0003。

## 数据保护与基础安全

| 领域 | 依据文件 | 说明 |
|---|---|---|
| 中国基线 | **GB/T 22239-2019** 等保2.0 | 按标准级别引用；条款级映射延后（第 4 节假设） |
| 欧盟个人数据 | **GDPR**（欧盟 2016/679） | 司机/个人位置数据属于个人数据——适用留存与最小化原则 |

## 明确不在方案包范围内

- 海关 / 全球贸易合规（HS 归类、关税计算、报关）——候选的兄弟方案包。
- 车辆停驶/行车记录仪与司机工时法定记录规则——仅作为车辆/司机资格*属性*
  被消费，不在此强制执行。
