# 00 · 干系人

| 干系人 | 对系统的关注点 | 主要接触面 |
|---|---|---|
| 货主物流经理 | 规划移动、选择承运商、拥有成本与服务 | 订单接入、装载规划、派车 |
| 调度员 / 计划员 | 日常执行：路线、招标、异常 | 路径规划、招标、异常控制台 |
| 承运商 / 分包商 | 接受招标、回报里程碑、获得付款 | 招标/EDI/API、里程碑馈送、发票 |
| 司机（自有车队） | 执行停靠点、采集送达证明 | 移动应用 / 车载终端集成 |
| 仓库（WMS）对手方 | 在月台交接已备货货物；接收退货 | 经核验的交接事件、ASN |
| 财务 / 应付账款 | 只在审计通过后支付运费 | 发票审计、结算批次、争议 |
| 客户 / 收货人 | 想要 ETA 与送达确认 | EPCIS 事件共享、门户 |
| 合规官（危险品、安全） | 确保危险品与安全规则成立；审计轨迹 | 危险品校验闸门、ISO 28000 控制 |
| 车队/资产经理（自有车队） | 车辆运力、准入资格、维护窗口 | 车辆主数据、运力模型 |
| 承运商记分卡负责人 | 度量承运商表现 | 里程碑准时率、理赔率 |

## 说明

- 「承运商」同时涵盖签约的 3PL 与自有车队；自有车队额外带来车辆与司机主
  数据，但不改变执行模型（ADR-0001 把车载终端硬件排除在外——它是一个集成
  *来源*）。
- 面向客户的可见性刻意基于事件发布（EPCIS、FR-021），而不只是门户，这样
  伙伴可以基于标准集成。
