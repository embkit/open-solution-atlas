# 04 · 集成

> 与外部系统和渠道的集成契约。ID 保持稳定；
> 每个流程均可追溯至需求和规则。
>
> ⚠️ ASSUMPTION — 接口选择和协议属于方案包设计。

## I. 外部集成点

| ID | 合作方 | 方向 | 用途 | 契约 |
|---|---|---|---|---|
| **I-01** | **PSP（支付服务提供商）** | 出站 | 托管支付字段、令牌化、授权、请款、退款 | PSP API；**平台自身范围的两个方向均不包含 PAN** |
| **I-02** | **承运商 / 物流** | 出站 | 创建面单、发货、跟踪、取消货运 | 承运商 API；异步、幂等 |
| **I-03** | **ERP / 会计** | 出站 | 库存过账、收入 | 批量/数据流；由对账推导得出 |
| **I-04** | **第三方平台** | 双向 | 接收订单数据流，输出商品目录和库存数据流 | 第三方平台 API；采用自有模式，由适配器映射 |
| **I-05** | **税务引擎** | 出站 | 按司法辖区对价格快照行项目计税 | 在计算价格快照时同步调用 |
| **I-06** | **身份 / 客户主数据** | 入站 | 跨渠道识别购买者身份 | 身份 API |
| **I-07** | **支付 / 资金管理渠道** | 入站 | 用于对账的结算实际数据 | 数据流 |
| **I-08** | **仓储管理** | 双向 | 实物执行状态 | WMS API |
| **I-09** | **欺诈 / 风险服务** | 入站 | 结算时的风险评分 | 同步、阻断，并规定明确的故障模式 |

## F. 内部流程

### F-01 — 定价与库存占用
1. 渠道适配器请求价格。
2. 定价服务解析价格表并评估生效的规则集版本。
3. 购物车应用商品的库存占用策略：预留（带过期时间）或不占用。
4. 响应包含已定价的行项目；对于预留，还包含过期时间。

### F-02 — 请款
1. 结算调用定价服务：评估并**冻结**价格快照。
2. 支付服务使用**平台签发的幂等键**进行授权。
3. 成功后，订单服务创建订单；库存服务按策略消耗库存。
4. 账本追加资金和库存变动。
5. 发生任何失败时，订单进入其取消路径（P-07）。

> 请注意执行顺序：价格快照在**授权之前**冻结，因此支付失败无法改变
> 已向客户承诺的内容。

### F-03 — 履约
1. 订单服务将行项目路由至履约服务。
2. 履约服务按策略选择来源（BR-15）。
3. WMS/承运商执行；状态以异步方式消费。
4. 订单服务将逐行履约结果归并到订单状态。

### F-04 — 售后冲正
1. 创建退货授权，并明确处置方式（BR-12）。
2. 收到商品后，按**记录的处置方式**重新入库或报废，而不是在收货时临时决定。
3. 支付服务以一项新操作和新的幂等键签发退款（BR-08）。
4. 账本记录库存变动和资金变动。

### F-05 — 对账
1. 读取账本以获取预期变动。
2. 从 I-07、I-02、I-08 读取外部实际数据。
3. 计算对账差异，并按照关闭程序予以关闭；其余差异按存续时长升级处理（BR-13）。

### F-06 — 渠道接入
1. 声明渠道（输入、支付、身份、履约来源）。
2. 依据渠道契约实现适配器。
3. 验证 PCI 处理方式（BR-10）；未通过的渠道将被阻断或记录为例外。
4. 依托共享核心启用该渠道。

## 各集成的故障模式契约

| 集成 | 要求采用的故障模式 |
|---|---|
| **I-01 PSP** | 超时必须视为*未知*，绝不能视为失败或成功；结果通过在相同幂等键下向 PSP 侧查询来确定 |
| **I-02 承运商** | 发货失败不会导致订单失败；而是转入取消路径，并记录原因 |
| **I-04 第三方平台** | 第三方平台数据流失败不得阻断平台自身的商品目录；各数据流独立重试 |
| **I-09 欺诈** | 欺诈服务不可用时，请在款时作出**故障关闭（fail-closed）**决策，而非绕过该服务 |
| **I-05 税务** | 税务引擎不可用时，价格快照计算失败——绝不采用默认税率 |

> 这一模式是：外部服务不可用时，只会让*外部*路径降级，而绝不会影响核心不变量。
> 唯一的例外是欺诈服务：它采用故障关闭策略，因为绕过该服务只会让这项控制沦为摆设。

## 渠道契约（每个适配器必须实现的内容）

| 方面 | 渠道需声明的内容 |
|---|---|
| **输入** | 订单如何到达（购物车会话、POS 设备、第三方平台数据流） |
| **支付路径** | 是否可用托管支付字段？是否可用令牌？使用哪条 POS/第三方平台路径？ |
| **身份** | 匿名 Cookie、应用安装 ID、账户、第三方平台购买者 ID |
| **履约来源** | 仓库、门店自提、供应商直发——以及各自的优先级 |
| **展示** | 公开哪些渠道变体属性 |

> 无法声明全部五项内容的适配器不是渠道变体，而是渠道分叉，
> BR-14 将予以拒绝。
